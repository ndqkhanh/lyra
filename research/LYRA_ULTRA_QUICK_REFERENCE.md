- **Core**: Rust + Tauri 2.0
- **Frontend**: React 18 + TypeScript
- **Database**: SQLite (local) + Qdrant (vectors)
- **LLMs**: Claude 3.5 Sonnet, GPT-4o, Opus 4.7, o1
- **Event Bus**: tokio channels (in-process)
