## QMD Deep Dive

### What is QMD?

**Query Markup Documents (QMD)** is a context compression technique mentioned in doc 318 that claims **95% token savings** through:
- Structured query markup for retrieval
- Selective document loading
- Hierarchical context assembly

### QMD vs Lyra Compression

| Dimension | QMD | Lyra Compression |
|-----------|-----|------------------|
| **Primary Use** | Document retrieval optimization | General agent state compression |
| **Token Savings** | 95% (claimed) | 70%+ (measured) |
| **Scope** | Retrieval phase only | Full agent lifecycle |
| **Techniques** | Query markup + selective loading | Summarization + deduplication + temporal pruning |
| **Lossiness** | Low (structured retrieval) | Medium (semantic compression) |
| **Integration** | Retrieval layer | Memory + context layers |
