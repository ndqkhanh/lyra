## Market Positioning Map

Plot competitors on two orthogonal axes (e.g., Price vs. Quality, Ease of Use vs. Power). Identify whitespace where no competitor plays.

## Competitive Moat Assessment

- **Switching Costs**: How hard is it for users to leave?
- **Network Effects**: Does value increase with more users?
- **Scale Economies**: Does the cost per unit drop with volume?
- **Brand**: Is there trust or recognition that is hard to replicate?
- **Technology**: Proprietary IP, patents, or data advantages?

## Teardown Methodology

1. Sign up and onboard as a new user
2. Map the core user journey step-by-step
3. Note friction points and moments of delight
4. Evaluate performance, polish, and reliability
5. Document pricing model and packaging

## Signal-to-Noise Evaluation

- Distinguish marketing claims from actual shipped capabilities
- Check public changelogs and release notes, not landing pages
- Verify claims via trial accounts, not screenshots
- Track feature velocity over time, not just the current snapshot
