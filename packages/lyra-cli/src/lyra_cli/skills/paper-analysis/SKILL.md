# Paper Analysis

## Structured Paper Extraction Template

- **Problem**: What research question or gap is addressed?
- **Method**: Approach, dataset, experimental setup, key parameters
- **Results**: Quantitative findings (effect sizes, confidence intervals, p-values)
- **Limitations**: Stated and unstated boundary conditions

## Methodology Evaluation Framework

- **Internal validity**: Confound control, randomization quality, attrition analysis
- **External validity**: Population sampling, ecological validity, generalizability
- **Construct validity**: Operationalization fidelity, measurement instrument validity
- **Statistical power**: Post-hoc power analysis, effect size justification

## Replication Planning Checklist

- Preregister analysis plan and stopping rules
- Document exact software versions, seeds, and hyperparameters
- Run sensitivity analysis on key preprocessing decisions
- Compare effect direction and magnitude (not just significance)

## Claim-Evidence Mapping

Map each claim to its supporting evidence and rate the strength: direct experimental support, correlational evidence, theoretical argument only, or unsupported assertion.

## Cross-Paper Synthesis Grid

Build a matrix with papers as rows and dimensions (population, intervention, outcome, setting, effect size) as columns to identify convergent and contradictory findings.

## Threat-to-Validity Taxonomy

- **Selection bias**: Non-random assignment or differential attrition
- **History effects**: External events during study period
- **Maturation**: Natural changes over time confounded with treatment
- **Testing effects**: Pretest influences posttest performance
- **Instrumentation**: Measurement changes between conditions
