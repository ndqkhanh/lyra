# Lyra Watermark

Content watermarking and provenance attribution for Lyra agents — Plan 14 (AGI Privacy).

## Overview

Lyra Watermark provides deterministic, verifiable content watermarking for any content
generated by Lyra agents. It uses SHA-256 based signatures embedded as detectable tags
within the content, enabling origin verification, tamper detection, and provenance chain
tracking.

## Features

- **Embedding** — embed a cryptographic watermark into any text content
- **Detection** — detect whether content contains a Lyra watermark
- **Extraction** — recover the full watermark payload from content
- **Verification** — confirm content originated from a specific agent
- **Tamper Detection** — detect modifications to watermarked content
- **Provenance Chains** — build immutable chains of provenance records

## Quick Start

```python
from lyra_watermark import WatermarkEngine

engine = WatermarkEngine()

# Embed a watermark
payload = engine.embed("Your content here", agent_id="my-agent")

# Detect an existing watermark
result = engine.detect(watermarked_content)
if result.watermarked:
    print(f"From agent: {result.payload.agent_id}")

# Verify agent origin
is_verified = engine.verify(watermarked_content, expected_agent_id="my-agent")
```

## Content Types

Watermarks can be applied to any content type via the `ContentType` enum:
`TEXT`, `CODE`, `IMAGE`, `AUDIO`, `DATA`.

## Watermark Methods

- **STATISTICAL** — statistical token bias patterns
- **CRYPTOGRAPHIC** — hash-based signatures
- **STEGANOGRAPHIC** — hidden in whitespace/formatting
- **SEMANTIC** — synonym substitution patterns
