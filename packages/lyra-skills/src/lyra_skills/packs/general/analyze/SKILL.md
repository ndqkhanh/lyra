1. Restate the goal in your own words; confirm with the user if ambiguous.
2. List constraints: time, dependencies, risk tolerance, existing architecture.
3. Identify 2-3 viable approaches; for each, note one pro and one con.
4. Pick the approach that best fits the constraints; explain why.
5. Before coding, run the approach past a second pair of eyes (reviewer agent or peer).
