id: unit-test
name: Unit Test
description: Write focused unit tests that verify a single function or method in isolation.
keywords:
  - unit test
  - unit testing
  - test function
  - test method
  - pytest
  - jest
---

1. Identify the function under test; list its inputs, outputs, and side effects.
2. Mock all external dependencies (APIs, databases, filesystem).
3. Write test cases: happy path, edge cases (empty, null, extremes), error paths.
4. Follow AAA: Arrange (setup), Act (call), Assert (verify).
5. Run the test in isolation; verify it passes and is deterministic.
