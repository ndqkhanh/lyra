---
id: convergent-thinking
name: Convergent Thinking
description: Evaluate, prioritize, and select the best ideas from a brainstorm using structured criteria.
keywords:
  - convergent
  - evaluate
  - prioritize
  - select
  - decision
  - vote
---

1. Define evaluation criteria before looking at ideas: impact, feasibility, novelty, alignment with goals. Weight each.
2. First pass — quick elimination: remove ideas that are clearly infeasible, off-mission, or already tried and failed.
3. Second pass — dot voting: each person gets 3-5 votes. Top-voted ideas advance. Discuss outliers (high variance in votes).
4. Third pass — impact/effort matrix: plot remaining ideas. High-impact/low-effort = do now. High-impact/high-effort = plan. Low-impact = reconsider.
5. For the top 2-3 ideas: write a one-paragraph sketch. What's the core insight? What must be true? What's the riskiest assumption?
6. Select the idea(s) to pursue. Document WHY each rejected idea was rejected (so it's not re-litigated).
7. Define the next step: not "investigate further" but a concrete, time-bound experiment to validate the idea.
