1. Check visual hierarchy: is the most important action visually dominant? Does the eye flow naturally?
2. Verify accessibility: color contrast (WCAG AA minimum), keyboard navigation, screen reader compatibility, focus states.
3. Assess consistency: do buttons, inputs, and navigation follow the same patterns everywhere?
4. Evaluate information architecture: can users find what they need in ≤3 clicks/taps?
5. Test edge cases: empty states, error states, loading states, long text, very small/big screens.
6. Review copy: is it clear, concise, and in the user's language? Are error messages actionable?
7. Produce a prioritized list of issues with before/after mockups or descriptions.
