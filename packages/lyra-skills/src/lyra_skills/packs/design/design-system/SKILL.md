name: Design System
description: Create and maintain consistent design tokens, components, and patterns.
keywords:
  - design system
  - tokens
  - components
  - components
  - patterns
  - style guide
---

1. Audit existing UI for inconsistencies: colors, spacing, typography, component variants.
2. Extract design tokens: colors (primary, secondary, semantic), spacing scale, typography scale, border radii, shadows.
3. Define component API: props, variants, states (default, hover, focus, disabled, error), accessibility attributes.
4. Document each component with: name, description, usage guidelines, code example, visual example, do/don't examples.
5. Establish a contribution process: who can add components, review criteria, versioning.
6. Plan adoption: identify high-impact components first, provide migration guides, track adoption metrics.
