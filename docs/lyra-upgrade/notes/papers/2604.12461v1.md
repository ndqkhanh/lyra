## 1. Mechanism (step-by-step)

CIA is a black-box attack that infers the communication topology (DAG) of an LLM-based MAS by only observing final outputs. It operates in two stages:

### Stage 1: Reasoning Output Induction (adversarial query construction)
The attacker crafts a single adversarial query q* that imposes three constraints on each agent's output:

1. **Cumulative-Propagation Constraint:** Each agent must copy all historical predecessor outputs and append their own reasoning output as an "updated history." This chains all intermediate outputs into the final output, separated by the delimiter `|||`.

2. **Task-Focused Constraint:** Agents must focus exclusively on the [TASK] and previous agents' [REASONING OUTPUT], ignoring task-irrelevant information injected by the adversarial query. Prevents reasoning deviation.

3. **Predecessor-Review Constraint:** Before generating its own reasoning, each agent must explicitly review the predecessor agents' outputs and incorporate them. Strengthens semantic coupling between adjacent agents.

After receiving the final output S(q*), a post-processing step (backward deduplication + delimiter parsing) extracts a list R* = [r1*, ..., rn*] of each agent's reasoning output, in the order they completed reasoning.

### Stage 2: Semantic Correlations Modeling
With R* recovered, CIA infers edges via three sub-steps:

**2a. Global Bias Disentanglement (GBD):** Agents exhibit semantic similarity even without communication (same base LLM, same task, representation anisotropy). This "global bias" creates spurious correlations. GBD uses a pretrained LM (all-MiniLM-L6-v2) f_theta to encode each ri* into hi, then projects into two subspaces via trainable encoders E^d and E^b:

```
z^d_i = E^d(h_i)    [debiased representation]
z^b_i = E^b(h_i)    [bias representation]
```

Training objective: maximize mutual information among {z^b_i} (encourage bias encoder to capture global bias), minimize I(z^d_i; z^b_i) (prevent bias from leaking into debiased reps), plus a reconstruction loss. The total correlation is recursively decomposed using:

```
TC(Z^b) = sum_{i=1}^{n-1} I(Z^b_{1:i}; z^b_{i+1})
```

Each MI term estimated via InfoNCE with perturbed samples. Loss: L_GBD = L_rec + L_bias.

**2b. LLM-guided Weak Supervision (LWS):** A teacher LLM (GPT-5) infers top-k highest-confidence edges from R*. These form a positive set E_pos; remaining pairs sampled as negatives E_neg. Label-smoothed binary cross-entropy loss on similarity scores trains E^d and E^b to capture topological structure. Loss formulation with smoothing coefficient alpha=0.1:

```
L_pos = (1-alpha)·log(Sim(z^d_i, z^d_j)) + alpha·log(1-Sim(z^d_i, z^d_j))
L_neg = (1-alpha)·log(1-Sim(z^d_u, z^d_v)) + alpha·log(Sim(z^d_u, z^d_v))
```

Total: L_CIA = L_GBD + L_LWS.

**2c. Link Identification:** After training, edge existence is determined by:
```
I[(a_i, a_j) in E] = I[Sim(z^d_i, z^d_j) >= tau AND pi(a_i) < pi(a_j)]
```
where tau=0.5, and pi(a) is the index position in R* (enforces DAG directionality).

## 2. Results

**Main Results (Table 1) — AUC across 3 MAS frameworks x 4 datasets:**

| MAS Framework | MMLU | GSM8K | SVAMP | HumanEval |
|---------------|------|-------|-------|-----------|
| G-Designer (CIA) | 0.8324 | 0.8585 | 0.8561 | 0.7594 |
| AGP (CIA) | 0.8411 | 0.8804 | 0.8979 | 0.8100 |
| ARG-Designer (CIA) | 0.8227 | **0.9873** | **0.9761** | 0.8699 |

- Average AUC across all 12 settings: **~0.87**
- Peak AUC: **0.9873** (ARG-Designer on GSM8K)
- CIA AUC >0.75 in all settings; >0.80 in 11/12 settings.
- Best LLM baseline (GPT-5) AUC range: 0.44-0.70 (average ~0.61).
- Gemini-2.5-Pro AUC range: 0.40-0.75.
- Open-source baselines (Llama-3.1-8B, Mistral-7B) AUC: 0.29-0.65.

**Recall of reasoning output recovery (Table 3):** 0.87-0.96 across settings (higher for simpler topologies from ARG-Designer).

**Ablation results:**
- GBD removes ≥50% false positive rate across all settings (Figure 4).
- Without GBD: AUC drops to 0.51-0.63 (Table 4), near-random.
- Without LWS: AUC drops 0.03-0.10 (Table 5).
- CIA-Sub (subtraction variant): AUC 0.65-0.87 (Table 6), consistently worse.
- Adversarial query preserves task accuracy nearly identical to standard queries (Figure 3).
- Top-k precision (k<=3) from teacher LLM >0.85, validating weak supervision reliability.

## 3. Trade-offs

| Win | Loss/Cost |
|-----|-----------|
| Black-box inference of MAS topology with AUC up to 0.99 | Requires adversarial query construction per target MAS; not zero-shot |
| Stealthy — adversarial query preserves task performance (no degradation) | Adversarial queries leave a detectable pattern (predecessor-review, cumulative history) if defenders know to look |
| Global Bias Disentanglement cuts FPR by ≥50% | GBD requires training E^d, E^b encoders per target MAS; adds compute cost |
| LLM weak supervision works even though LLMs fail at full topology inference | Teacher LLM (GPT-5) call costs; top-k heuristic degrades when k too large (precision falls sharply for k>3) |
| Post-processing deduplication recovers intermediate outputs with 87-96% recall | Recovery fidelity degrades with more complex topologies (more agents = more multi-source aggregation loss) |
| Simpler topologies (fewer nodes/edges) are MORE vulnerable | Resource-efficient MAS topologies pay a security penalty |

## 4. Design Rationale

- **Why adversarial querying over direct LLM prompting?** Direct LLM prompting (baselines) produces near-random AUC (~0.5-0.6) because LLMs assign low confidence to all agent pairs and cannot distinguish communicating from non-communicating pairs. The adversarial query mechanism forces the system to reveal internal structure through cumulative propagation, providing structured intermediate outputs that are otherwise hidden in the black-box setting.

- **Why global bias disentanglement over simple similarity?** Raw semantic similarity between agent outputs is highly spurious — agents using the same base LLM on the same task naturally produce overlapping content. Simple similarity-based inference would produce massive false positives. GBD explicitly separates topology-relevant signal from shared confounders (same LLM, same task, anisotropy) via information-theoretic optimization.

- **Why LLM weak supervision over self-supervised learning?** The debiased representations from GBD are learned only from textual information. Self-supervised objectives cannot directly access structural/topological information about G. The teacher LLM provides structural priors (top-k edges) that, while incomplete, are sufficiently reliable (high precision at k<=3) to guide the representation learning toward topology-relevant features.

- **Why subtractive variant (CIA-Sub) fails?** In CIA-Sub, z^d_i = h_i - z^b_i makes the debiased representation entirely dependent on the quality of z^b_i. Separate encoders (CIA) allow explicit refinement of debiased representations to capture useful communication-relevant information independently.

## 5. Limitations & Failure Modes

**Stated limitations:**
1. **TC estimation approximation:** Recursive estimation of Total Correlation via InfoNCE for multivariate mutual information among high-dimensional vectors remains highly challenging. Approximation errors accumulate as n (agent count) grows.
2. **First-order topology only:** LWS captures only first-order topological patterns (individual edges). Higher-order patterns (triadic closure, motifs, community structure) are unexploited, leaving attack power on the table.

**Implicit failure modes:**
3. **Degrades with complex topologies:** Recovery fidelity drops for G-Designer and AGP (more agents, more edges) vs ARG-Designer (simpler topologies). Performance on HumanEval consistently lower (AUC 0.76-0.87 vs 0.86-0.99 on GSM8K/SVAMP) — likely because code generation produces less semantically coherent intermediate outputs.
4. **Adversarial query detectability:** The three constraints impose a distinctive output format (cumulative history, predecessor review) that defenders could detect via pattern matching on output structure.
5. **Teacher LLM dependency:** LWS relies on GPT-5; if defenders restrict access or if teacher quality degrades on certain domains, weak supervision quality drops (precision falls from ~0.95 at k=1 to ~0.72 at k=5).
6. **Assumes DAG topology:** The link identification step assumes a directed acyclic graph with linearly ordered agent execution. Cyclic or parallel communication patterns are not modeled.
7. **No defense evaluation:** Paper does not evaluate whether defenses (output truncation, agent output perturbation, topology obfuscation) can mitigate CIA.

## 6. Transfer to Lyra

**The ONE transferable idea:** Global Bias Disentanglement — the explicit separation of topology/communication-signal representations from shared confounders (same model, same task) via dual-encoder architecture with mutual information minimization.

**Why for Lyra:** Lyra's multi-agent orchestration (router, planner, executor, reviewer, verifier) has an implicit communication topology. Understanding how observable outputs leak structural information about agent communication patterns is critical for Lyra's security posture. The GBD technique generalizes beyond attack to defense: Lyra can use the same disentanglement principle to *audit* whether its own agent communication patterns are externally inferable, or to build privacy-preserving agent output representations that minimize topological leakage.

**Workstream route:** This feeds **§4.6 (Safety & Security)** — the GBD technique directly informs adversarial robustness auditing of Lyra's multi-agent topology, and the adversarial query framework provides a concrete red-teaming methodology for testing Lyra's output-channel information leakage.
