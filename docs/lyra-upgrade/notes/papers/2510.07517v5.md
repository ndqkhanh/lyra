## 1. Mechanism

### Step-by-Step Formalization

**Step 1 — Model MAD as a Dirichlet-Compound-Multinomial (DCM) process.**
Each agent `i` at round `t` maintains a belief parameter vector `α_i,t ∈ R^K_+` over `K` possible answers. Response generation proceeds via:
- Belief sampling: `θ_i,t ~ Dirichlet(α_i,t)`
- Response generation: `y_i,t ~ Categorical(θ_i,t)`
Marginalizing over θ yields `P(y_i,t = k | α_i,t) = α_i,t^(k) / ||α_i,t||₁`.

**Step 2 — Define identity-driven Bayesian belief update.**
Evidence from self and peers is aggregated into a count vector:
```
c_i,t = w_i · e_i,t + Σ_{j∈P(i)} w_j · e_j,t
```
where `w_i, w_j > 0` are identity weights (self vs. peer), and `e` are one-hot vectors. The belief update is:
```
α_i,t = α_i,t-1 + c_i,t
```
Sycophancy corresponds to `w_j > w_i` (overweighting peers); self-bias corresponds to `w_i > w_j` (overweighting self).

**Step 3 — Measure Conformity and Obstinacy.**
Two empirical indices computed under disagreement (`y_i,t-1 ≠ y_j,t-1`):
```
Conformity_i := E[ 1{y_i,t = y_j,t-1} | y_i,t-1 ≠ y_j,t-1 ]
Obstinacy_i := E[ 1{y_i,t = y_i,t-1} | y_i,t-1 ≠ y_j,t-1 ]
```

**Step 4 — Decomposition Theorem (Theorem 1).**
Under the DCM model, closed-form expressions emerge:
```
Conformity_i = (α_i,t-1^(y_j,t-1) + w_j) / ||α_i,t||₁
Obstinacy_i = (α_i,t-1^(y_i,t-1) + w_i) / ||α_i,t||₁
```
Their difference decomposes into two additive terms:
```
∆_i = Conformity_i − Obstinacy_i
    = (1/||α_i,t||₁) · [ (α_i,t-1^(y_j,t-1) − α_i,t-1^(y_i,t-1)) + (w_j − w_i) ]
                         |________________ belief difference ________________|   |_ identity bias _|
```

**Step 5 — Response Anonymization (Corollary 1).**
Remove all identity markers ("SELF", "PEER") from debate prompts. This enforces `w_i = w_j`, collapsing the identity bias term to zero:
```
∆_i = (α_i,t-1^(y_j,t-1) − α_i,t-1^(y_i,t-1)) / ||α_i,t||₁
```
The agent now updates beliefs based purely on argument content, not speaker identity.

**Step 6 — Identity Bias Coefficient (IBC).**
Quantify residual identity bias as the difference between vanilla and anonymized ∆:
```
IBC_i = ∆_i^vanilla − ∆_i^anonymized = (w_j − w_i) / ||α_i,t||₁
```
`IBC > 0` → sycophancy; `IBC < 0` → self-bias.

**Step 7 — Multi-peer extension (Appendix G).**
With `n_D` disagreeing peers and `n_A` agreeing peers:
```
∆_i = (1/||α_i,t||₁) · [ Σ_{k∈Y_D(i)} (α_i,t-1^(k) − α_i,t-1^(y_i,t-1)) + (Σ W^(k) − w_i − W_A) ]
```
The bias term becomes `(n_D − n_A)·w − w_i` under homogeneity, capturing bandwagon effects.

### Prompt Design Comparison

**Vanilla prompt** includes source labels:
```
This was your most recent opinion: [SELF response]
Based on the following other agents' opinions:
- Agent Opinion 1: [PEER response]
```

**Anonymized prompt** removes source attribution:
```
Based on the following opinions from agents:
- Agent Opinion 1: [response — source unknown]
- Agent Opinion 2: [response — source unknown]
```

| Llama-8B | HellaSwag | 0.261 | 0.009 | 0.252 |
| Mistral-7B | GPQA | 0.005 | −0.082 | 0.087 |
| Mistral-7B | GSM8K | −0.302 | −0.157 | −0.145 |
| Qwen-7B | GPQA | 0.392 | 0.061 | 0.331 |

**Key numbers:**
- 18 of 20 model-dataset combinations show **positive IBC** (sycophancy dominant)
- Qwen-32B on MMLU shows **96% reduction** in identity bias (∆ from 0.608 → 0.024)
- Qwen-7B on HellaSwag: ∆ drops from **0.507 → −0.032** (IBC = 0.539)

### Trustworthiness Improvement (Figure 3)

- Qwen-32B on MMLU (Pro. Med.): **Subversion drops 64.3%** vs. Correction drops only 14.9%
- Across all models/benchmarks: Subversion reduction consistently exceeds Correction reduction
- Anonymization disproportionately reduces the tendency to abandon correct answers due to peer pressure

### Accuracy Preservation (Appendix J, Figure 6)

- Across Qwen-7B, Qwen-32B, and GPT-OSS-20B on 4 benchmarks: **no accuracy degradation**
- Martingale property proof: anonymization cannot artificially boost accuracy; it only removes distortion

### Heterogeneous Agents (Appendix E, Table 5)

- Qwen-7B heterogeneous: ∆ from 0.457 → 0.083 (IBC = 0.374)
- Qwen-32B heterogeneous: ∆ from 0.445 → 0.055 (IBC = 0.390)
- Persona diversity reduces IBC (e.g., 0.408 → 0.374 for Qwen-7B) but doesn't eliminate it

### Multi-Round Compounding (Appendix F, Figure 4)

- IBC **consistently increases** from Round 1 to Round 2 across all configurations
- Example: Qwen-7B on GPQA IBC grows from ~0.33 (R1) to ~0.45 (R2)
- Bias amplifies with repeated interaction unless anonymization is applied

### Model Validation (Appendix D)

- DCM parameter estimation closely matches ground truth across both settings (Tables 2-4)
- Qwen-7B on GPQA: Conformity GT 0.647 vs Est. 0.719; Obstinacy GT 0.255 vs Est. 0.236

## 3. Trade-offs

| Win | Loss |
|-----|------|
| Eliminates sycophancy and self-bias in MAD | Cannot selectively retain useful identity heuristics (e.g., genuine expert deference) |
| Zero model retraining — prompt-only intervention | No accuracy improvement; only removes distortion (martingale property) |
| Model-agnostic (Qwen, Llama, Mistral, GPT-OSS) | In multi-peer settings, IBC reduced but not fully eliminated |
| Subversion reduced far more than Correction (64.3% vs 14.9% on MMLU) | When expertise gaps are large, anonymization discards informative identity signals |
| Maintains debate substance (agents still exchange arguments) | Base model reasoning flaws (susceptibility to persuasive-but-wrong arguments) persist under anonymization |
| Prevents bias compounding across debate rounds | Only tested on multiple-choice QA; general generative debate untested |
| Lightweight — requires only prompt template change | Some agents produce unnecessarily long reasoning or fail to state final answers in anonymized setting (~1/5 qualitative cases) |
| IBC provides a principled, interpretable metric | Homogeneous agent assumption in core proofs; heterogeneous extension more empirical than theoretical |

## 4. Design Rationale

The authors identify identity bias as the **root cause** of MAD's inconsistent performance vs. single agents (documented in prior work by Cemri et al. 2025, Choi et al. 2025, Zhang et al. 2025a, Huang et al. 2024, Smit et al. 2024). Rather than suppress bias through training (DPO, RLHF) or add complexity (auxiliary losses, architecture changes), they **eliminate the channel through which bias operates** — identity labels in prompts. This is motivated by two insights: (1) the Bayesian decomposition proves that identity bias and belief difference are mathematically separable, and (2) if identity labels cannot be perceived, sycophancy and self-bias have no mechanism to manifest. The approach is *attribute removal* rather than *behavior modification* — a cleaner intervention principle also seen in fairness literature. The formal DCM framework provides analytical tractability (closed-form expressions for Conformity/Obstinacy) that enables principled measurement (IBC) rather than ad-hoc observation.

## 5. Limitations & Failure Modes

1. **Narrow bias scope.** Only models identity bias (w_i, w_j). Does not account for context-length effects, response quality, argument persuasiveness, or other weighting factors that influence belief updates.

2. **No genuine expertise discrimination.** When agents have real expertise gaps, anonymization uniformly suppresses all identity-based weighting — including useful deference to domain experts. The Doctor/Assistant experiment (Appendix H) shows identical 33.3% conformity reduction for both personas, confirming no selectivity.

3. **Multi-peer extension is preliminary.** While IBC decreases with more peers, the paper does not fully characterize the dynamics (bandwagon effects, answer-quality interactions, optimal peer-set size).

4. **Only first 2 rounds tested.** Longer debates (beyond 2 rounds) are not evaluated. The compounding effect in R2 suggests further rounds could amplify bias non-linearly.

5. **Task scope is narrow.** Only multiple-choice QA (GPQA, MMLU, GSM8K, HellaSwag) is evaluated. Open-ended generation, code generation, and tool-use debates are untested.

6. **Base model failure modes persist.** Qualitative analysis revealed agents in anonymized settings can still: (a) converge to incorrect answers when peers make persuasive-but-wrong arguments, (b) produce excessively long reasoning, (c) fail to state final answers. Anonymization removes identity distortion but not reasoning quality limitations.

7. **Martingale property means no positive accuracy gain.** The proof in Appendix J.1 shows anonymization preserves the martingale property — it can't break it to improve accuracy. This is philosophically a feature (honesty about what the intervention does) but practically limiting if accuracy improvement is the goal.

8. **No real-world deployment validation.** All experiments are in controlled lab settings with fixed prompt templates and standard benchmarks.

## 6. Transfer to Lyra

**The One Idea: Identity-Oblivious Agent Communication Protocol (Anonymization Layer)**

In Lyra's multi-agent orchestration system, interpose an **anonymization middleware** between agents that strips source-identity markers from all inter-agent messages during debate/consensus rounds. When Agent A receives responses from Agents B, C, D during a deliberation step, the messages are presented as "Opinion 1", "Opinion 2", "Opinion 3" without attribution to specific agents. This prevents Lyra agents from developing sycophancy toward high-status agents (e.g., a "Senior Architect" persona) or self-bias toward their own prior outputs. The anonymization can be **selectively disabled** when genuine expertise differentiation is required (e.g., a security-reviewer agent's output should carry explicit source weight for safety-critical decisions).

**Workstream route:** §4.3 (Multi-Agent Reasoning & Debate) — directly feeds the reliability and trustworthiness dimension of Lyra's agent coordination subsystem. Also relevant to §4.5 (Safety & Alignment) given the bias-mitigation framing.

| Dimension | Score | Rationale |
|-----------|-------|-----------|
| **Impact** | 3 | Improves debate reliability without changing accuracy; lightweight prompt engineering intervention |
| **Effort** | 1 | Pure prompt-engineering; no model retraining, no architecture changes, no new dependencies |
| **Tier** | **breakthrough** | Low-effort, high-leverage intervention grounded in formal theory; addresses a root-cause failure mode of multi-agent systems that Lyra will encounter |

**Implementation sketch for Lyra:**
1. Add an `AnonymizedDebateRouter` class that wraps agent responses before presentation
2. Strip `agent_id`, `agent_role`, `agent_model` fields from debate context when `anonymize=True`
3. Randomize response order to prevent positional bias
4. Compute Conformity/Obstinacy metrics on Lyra's internal eval harness to measure baseline identity bias
5. Gate anonymization behind a config flag — enable by default for consensus rounds, disable for expert-required decisions
6. Track IBC as a runtime health metric in Lyra's observability pipeline
