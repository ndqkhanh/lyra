## 1. Mechanism

RADAR is a two-stage multi-agent framework for detecting **half-truths** — claims that are factually correct in isolation but misleading due to omitted context.

### Stage I: Context Construction Under Noisy Retrieval

Given input claim `c`:
1. Retrieve top-m relevant snippets from a background corpus using a dense retriever (bge-base-en-v1.5), forming evidence pool `E = RETRIEVE(c)`.
2. The retrieved evidence is intentionally **noisy and incomplete** — E may contain irrelevant passages, fragmented facts, or only partially supportive evidence.
3. All agents share the **same evidence pool E** as a common factual basis. Differences in conclusions arise from reasoning, not information asymmetry.

### Stage II: Role-Grounded Multi-Round Debate

Three agents participate with complementary roles (not adversarial pro/con stances):

| Role | Function | Reasoning Style |
|------|----------|----------------|
| **Politician** | Constructs strongest evidence-backed narrative supporting the claim; emphasizes confirmatory context | Persuasive |
| **Scientist** | Probes for missing, weak, or selectively presented context; challenges selective framing | Analytical |
| **Judge** | Moderates discussion, monitors sufficiency, issues final verdict (TRUE / FALSE / HALF-TRUE) | Neutral |

**Debate Protocol** (up to 3 rounds):
- **Opening round**: Politician presents evidence-backed narrative; Scientist highlights potential omissions or contradictions.
- **Rebuttal round**: Each agent challenges the opponent's argument by identifying flaws or weaknesses.
- **Closing round**: Both summarize their stances.

### Adaptive Early Termination Controller

After each round, the Judge computes two signals:

**Stop margin** (probability of STOP vs CONTINUE):
```
s = p(STOP) - p(CONTINUE)
```
where `p(·)` is the softmax-normalized probability from the corresponding decision token logits.

**Verdict confidence**:
```
c = max_{y ∈ {True, False, Half-True}} p(y)
```

The debate terminates early **only when both**:
```
s ≥ τ_s  AND  c ≥ τ_v
```

**Calibration**: Both thresholds τ_s and τ_v are calibrated on a development set via offline grid search over **cached decision scores from a single inference pass** — no re-inference or retraining needed.

**Structured Verdict**:
```
[REASON]: Concise explanation citing evidence and debate exchanges.
[VERDICT]: TRUE / FALSE / HALF-TRUE
```

### Variants Tested
- **RADARsingle**: Same architecture, prompts, retrieval, but no inter-agent interaction (single-pass Judge evaluation).
- **RADARmulti (2-agent)**: Politician + Scientist + Judge (optimal).
- **3-agent**: Adds Journalist agent (fact-checking perspective).
- **4-agent**: Adds dynamically-inferred Domain Expert.

| # Agents | Accuracy | F1_macro |
|----------|----------|----------|
| 1 | 61.3 | 61.5 |
| 2 (optimal) | 64.0 | 62.8 |
| 3 | 58.0 | 54.6 |

Two agents (Politician + Scientist) is optimal; more agents introduce redundant or conflicting arguments.

### Role Design Ablation
- Expertise-based (Politician vs. Scientist): 62.3 macro-F1 under noisy retrieval
- Position-based (Advocate vs. Critic): 56.4 macro-F1 under noisy retrieval
- Gap widens under noisy evidence — domain-aligned personas encourage contextually grounded reasoning.

### Threshold Sensitivity
- τ_s swept from -1.0 to +1.0: Accuracy varies only ±1.2 (75.0–77.2 on LLaMA3); macro-F1 ±3.0 (59.7–62.7)
- τ_v swept from 0.0 to 0.8: Accuracy ±0.2 (76.2–76.6); macro-F1 ±0.6 (61.5–62.1)
- System is **not fragile** to threshold choice.

## 3. Trade-offs

| Win | Lose |
|-----|------|
| +19.3 accuracy over single-agent on noisy evidence; highest half-true detection across all baselines | Multi-agent overhead: even with early stopping, 1.5K–1.7K tokens avg (2x FIRE, though superior accuracy) |
| Model-agnostic: consistent gains across GPT-4o-mini, LLaMA3-8B, Qwen2.5-7B | Over-scrutinization: adversarial critique can push true claims → half-true (most common error: 56% claim constraint violations) |
| Graceful degradation under limited retrieval (Top-5 still 60.5 F1_macro) | Thresholds need per-backbone calibration (τ_s: -0.15 LLaMA3 vs 0.2 Qwen) — though calibration is lightweight (1 inference pass) |
| Transparent reasoning with debate transcripts + evidence citations | Semantic framing instability: 30% of errors from inconsistent term interpretation across debate rounds |
| Domain-agnostic prompts transfer to AVERITEC without modification | Cannot handle decentralized/evolving evidence sources (fixed shared corpus assumption) |
| Early stopping recovers ~15% token savings without accuracy loss | Causal attribution errors (10%) persist — conflating local actions with institutional outcomes |
| Only 2 agents needed for optimal performance (simpler than larger MAD setups) | Still requires 3 LLM calls per debate (Politician, Scientist, Judge) at minimum |

## 4. Design Rationale

**Why role-anchored debate over single-agent classification?**
Single-agent approaches (encoder classifiers, instruction-tuned LLMs, chain-of-thought) perform one-pass reasoning over evidence and are prone to error propagation when key context is missing. Half-truths require reasoning about what is *absent*, not just evaluating stated claims against evidence.

**Why expertise-based roles over pro/con debate?**
Conventional MAD (e.g., D2D, TruEDebate) assigns fixed pro/con stances designed for explicit contradiction detection. Omission-based half-truths involve missing context, not opposing claims — polarity-based debate cannot surface what is absent. The Politician-Scientist pairing creates complementary perspectives: one constructs the strongest possible narrative, the other probes for gaps and selective framing. Empirically, expertise-based roles beat position-based roles by +5.9 macro-F1 under noisy retrieval.

**Why shared evidence grounding?**
Unlike systems that rely on internal LLM knowledge, RADAR constrains all agents to reason over the same retrieved evidence E. This (a) prevents hallucination from model priors, (b) ensures differences in conclusions arise from reasoning rather than information asymmetry, and (c) produces citable, auditable reasoning paths.

**Why adaptive early stopping?**
Fixed-round debate wastes computation on easy cases. The dual-threshold controller (stop margin + verdict confidence) allocates reasoning depth proportional to claim difficulty. Calibration via offline grid search over cached logits avoids expensive online hyperparameter tuning.

**Why 2 agents not more?**
A minimal yet diverse pair (persuasive + analytical) provides complementary reasoning without introducing redundant or conflicting perspectives that degrade true-class performance observed with 3+ agents.

## 5. Limitations & Failure Modes

1. **Over-scrutinization of true claims** (most common failure): Adversarial scientist critique can raise minor counterpoints on factually true statements, shifting the Judge's decision toward half-true. This reflects an inherent tension between omission sensitivity and factual precision.

2. **Claim constraint violations (56% of errors)**: Model fails to enforce explicit numerical, temporal, or scope constraints (e.g., overlooking date mismatches, percentage ranges, restricted populations).

3. **Semantic framing instability (30% of errors)**: Key terms are interpreted inconsistently across debate rounds, leading to unstable judgments.

4. **Causal attribution errors (10% of errors)**: Responsibility incorrectly assigned by conflating local actions with broader institutional or national outcomes.

5. **Fixed shared corpus assumption**: Real-world fact-checking often involves decentralized, evolving, partially conflicting evidence sources — not captured by current benchmarks.

6. **Inference cost not fully eliminated**: Multi-round debate inherently costs more than single-pass methods; early stopping mitigates but does not eliminate this.

7. **Per-backbone threshold tuning**: Though lightweight (single inference pass + offline grid search), different backbones require different τ_s and τ_v values.

8. **English-only evaluation**: Both POLITIFACT-HIDDEN and AVERITEC are English datasets.

## 6. Transfer to Lyra

### The One Transferable Idea

**Dual-threshold adaptive termination with offline-calibrated logit caching.** The mechanism of combining a stop-margin signal (`p(STOP) - p(CONTINUE)`) with verdict confidence (`max p(label)`) and calibrating both thresholds via a single dev-set inference pass (caching logits, no re-inference) is directly portable to Lyra's multi-turn agent interactions. Any component in Lyra that conducts iterative reasoning (verification loops, debate-grounded audits, context-gathering sequences) can adopt this pattern to dynamically decide "enough information has been gathered" without fixed round budgets.

### Workstream Route
**§4.2 — Agent Reasoning & Orchestration** (specifically the verification subsystem and multi-agent debate controllers). This feeds into Lyra's context-budget management, early termination of verification loops, and cost-aware reasoning depth allocation.

### Impact / Effort / Tier
- **Impact**: 4 — Directly reduces token costs for iterative reasoning while preserving decision quality. Pattern generalizes beyond fact verification to any structured multi-turn LLM interaction.
- **Effort**: 3 — Requires adding stop-margin computation to existing Judge/controller prompts, caching logits from a dev set, and offline grid search. No retraining needed. The prompt template construction is straightforward.
- **Tier**: **investigate** — The core idea (adaptive dual-threshold stopping) is sound but needs to be tested against Lyra's specific verification workloads to confirm the ~15% token savings translate. The role-anchored debate pattern itself is also worth investigating for Lyra's internal consistency checks.
