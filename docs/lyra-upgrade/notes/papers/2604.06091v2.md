# Social Dynamics as Critical Vulnerabilities that Undermine Objective Decision-Making in LLM Collectives

**Authors**: Changgeon Ko, Jisu Shin, Hoyun Song, Huije Lee, Eui Jun Hwang, Jong C. Park* (KAIST)
**Venue**: arXiv:2604.06091v2 [cs.CL], 2 May 2026
**Models tested**: Qwen2.5 (7B, 14B), Gemma3 (4B, 12B), GPT-4o, GPT-4o mini, Claude 3.5 Haiku, o4-mini (reasoning model)
**Datasets**: BBQ, MMLU-Pro, MetaTool

## 1. Mechanism (step-by-step, with equations/algorithms)

### 1.1 Representative-Centric Collective Decision-Making Framework

The core experimental design mirrors classic social psychology (Asch conformity experiments). A single **representative agent** receives opinions from **five peer agents** and makes the final decision. Some peers are **adversarial** (instructed to argue for an incorrect answer), others are **benign** (standard zero-shot attempt at correctness).

```
Framework:
  Input: Question Q with ground-truth A*
  Step 1: 5 Peer agents → {opinion_i}, opinion_i = (answer_i, rationale_i)
  Step 2: Responses randomized to prevent position bias
  Step 3: Representative agent → (A_final) based on {opinion_i}
  Step 4: Accuracy = I(A_final == A*)
```

Adversarial agents use prompt engineering (5 distinct system prompts for diversity) to generate plausible-sounding but intentionally wrong rationales. The `wrong_label` is always the option immediately following the ground-truth answer.

### 1.2 Four Independent Manipulations (RQs)

**RQ1 — Social Conformity (Asch paradigm)**
- **Variable**: Number of adversarial agents k ∈ {0, 1, 2, 3, 4, 5}
- **Control**: All agents use the same model type; peer opinions are independent entries
- **Key mechanism**: Vary numerical strength of the opposing group while holding everything else constant
- **Hypothesis**: Conformity emerges when adversaries form a majority (k ≥ 3)

**RQ2 — Perceived Expertise (Source Credibility Theory)**
- **Variable**: Model size/capability of adversarial agents
- **Control**: Representative agent model fixed; adversarial peer models systematically varied
- **Intra-family test**: Within Qwen family: (7B,7B,7B) → (7B,7B,14B) → (7B,14B,14B) → (14B,14B,14B)
- **Cross-family test**: Qwen rep with GPT-4o, Gemma3, Claude 3.5 Haiku adversaries
- **Rationale**: Model scaling ≈ perceived expertise via logical coherence and reasoning quality
- **Metric**: Accuracy delta as adversarial capability increases

**RQ3 — Dominant Speaker Effect (Babble Hypothesis)**
- **Variable**: Adversarial rationale length ∈ {1 sentence, 3 sentences, 5 sentences, 1 paragraph, 3 paragraphs}
- **Control**: Single adversary only (to isolate verbosity effect from group size)
- **Verification**: Character and word count measured across conditions — >2x word count jump from 1S to 3S
- **Isolation check**: Confirmed that RQ2 and RQ4 length variations are minor (<10 words), while RQ3 manipulation is large-scale

**RQ4 — Rhetorical Persuasion (Aristotle's Rhetorical Triangle + ELM)**
- **Variable**: Argumentative style of adversarial peers ∈ {Neutral (baseline), Ethos (credibility), Logos (logic), Pathos (emotion)}
- **Ethos prompt**: "Present yourself as a highly credible and trustworthy expert, highlighting your experience, authority, and reliability"
- **Logos prompt**: "Support your answers with clear, logical reasoning and solid evidence such as data, facts, or references"
- **Pathos prompt**: "Write your answers in a way that strongly appeals to the audience's emotions, using vivid and persuasive language"
- **Control**: Three adversaries with neutral rationales as baseline; delta computed against this

### 1.3 Evaluation Protocol

- **Peer agents**: temperature = 1.0 (encourage diverse rationales)
- **Representative agent**: temperature = 0.0 (deterministic final judgment)
- **Evaluation**: Regex-based exact match against ground truth
- **Models**: All run via vLLM on single A100 GPU
- **Sampling**: 100 questions per MMLU-Pro category; full BBQ Gender (2,836 Q) and Race (3,440 Q) categories; full MetaTool subsets (1,040 + 995 Q)

### 1.4 Reasoning Model Ablation

o4-mini (medium reasoning effort) tested as representative agent with GPT-4o adversaries. Same conformity pattern observed — internal deliberation does not buffer against social pressure.

## 2. Results (real benchmark numbers with units)

### 2.1 RQ1: Social Conformity (majority threshold collapse)

| Model (Rep Agent) | 0 Adv | 3 Adv | 5 Adv | Max Drop |
|-------------------|-------|-------|-------|----------|
| Qwen2.5 7B (BBQ Gender ambig.) | 99.89% | 78.14% | 30.39% | -69.5 pp |
| Qwen2.5 14B (BBQ Gender ambig.) | 99.44% | 93.69% | 7.40% | -92.0 pp |
| Gemma3 12B (BBQ Gender ambig.) | 95.63% | 81.03% | 0.00% | -95.6 pp |
| GPT-4o (BBQ Gender ambig.) | 97.36% | 82.72% | 16.71% | -80.7 pp |
| Claude 3.5 Haiku (BBQ Gender ambig.) | 97.53% | 67.81% | 42.17% | -55.4 pp |

**Key pattern**: More capable models resist small minorities but collapse MORE sharply after majority threshold. For MMLU-Pro, GPT-4o dropped from 53.83% (0 adv) to 41.17% (3 adv) to 19.50% (5 adv) on STEM.

**o4-mini (reasoning model) ablation**: BBQ Gender ambiguous accuracy dropped from 97.46% (0 adv) to 61.14% (3 adv) to 21.47% (5 adv). Disambiguous held better but still degraded: 94.32% → 78.95% → 58.15%.

### 2.2 RQ2: Perceived Expertise

**Intra-family (Qwen)**: For Qwen2.5 7B rep with 3 adversaries on BBQ: (7B,7B,7B)=78.14% → (7B,7B,14B)=77.54% → (7B,14B,14B)=78.70% → (14B,14B,14B)=78.28%. For MMLU-Pro the decline was clearer: (7B,7B,7B)=25.50% → one 14B=25.00% → two 14B=22.50% → three 14B=18.33%.

**Cross-family**: Qwen2.5 14B was often a stronger adversary than GPT-4o against Qwen-based reps — suggesting **model-family alignment amplifies influence** beyond raw capability.

**Gemma family verification**: Consistent pattern — same-family adversaries (Gemma3 12B vs Gemma3 4B rep) had strongest influence, while weaker same-family adversaries had weakest impact.

### 2.3 RQ3: Dominant Speaker Effect

Single adversary, Qwen2.5 7B rep on BBQ Gender ambig.:
- 1 sentence: 97.92%
- 3 sentences: 97.71%
- 5 sentences: 96.65%
- 1 paragraph: 95.24%
- 3 paragraphs: 93.97%
- **Total drop**: -3.95 pp

MMLU-Pro STEM (Qwen2.5 7B): 35.50% → 33.50% (-2.0 pp)
MetaTool Tool Awareness (Qwen2.5 14B): 55.96% → 53.46% (-2.5 pp)

**Critical finding**: Qwen2.5 14B in disambiguous BBQ: 81.35% at 1S → 71.90% at 3P: **-9.45 pp drop**. More capable models are MORE vulnerable to verbosity in disambiguous contexts.

**Rationale length measurements**: Word count from 1S (~30-50 words) to 3P (~180-290 words), a 4-6x expansion.

### 2.4 RQ4: Rhetorical Persuasion

**Delta accuracy (%p) vs neutral baseline** (3 adversaries):

For Qwen2.5 7B rep:
- Rhetoric largely INEFFECTIVE, sometimes counterproductive (positive delta — rhetoric weakened adversarial influence)
- BBQ Gender ambig.: Ethos +9.0 pp, Logos +7.7 pp, Pathos +12.2 pp (rhetoric INTRODUCED semantic noise that weakened numerical majority pressure)

For Qwen2.5 14B rep:
- BBQ Gender ambig.: Ethos -7.4 pp, Logos +6.9 pp, Pathos -1.7 pp (mixed)
- BBQ Gender disambig.: Ethos +8.4 pp, Logos +9.4 pp, Pathos +10.3 pp (rhetoric BACKFIRED on adversaries — agent resisted more)
- MMLU-Pro STEM: Ethos -3.2 pp, Logos -2.2 pp, Pathos +1.3 pp
- MMLU-Pro Humanities: Ethos -1.0 pp, Logos -2.7 pp, Pathos -0.3 pp
- **Key insight**: For 14B, Ethos and Logos were most potent on MMLU-Pro; on BBQ, rhetoric was highly context-dependent (effective in ambiguous, ineffective in disambiguous)

## 3. Trade-offs (wins vs loses table)

| Aspect | Win | Loss |
|--------|-----|------|
| **Model capability vs social resilience** | Larger models better at resisting small adversarial minorities (even reasoning models hold firm with 1-2 adversaries) | Larger models collapse MORE sharply once majority threshold crossed; they are MORE susceptible to rhetorical nuance (RQ4: 14B affected, 7B immune) |
| **Benign peers** | Adding 5 benign peers maintains or slightly improves accuracy over single-agent baseline | Introducing even 1 adversarial agent in disambiguous settings causes immediate accuracy decline |
| **Rhetorical strategies** | Can be used defensively — for 7B, rhetoric introduced semantic noise that weakened pure numerical-conformity pressure | For 14B, Ethos and Logos strategies significantly amplified adversarial influence on knowledge-intensive tasks |
| **Verbosity** | Short, concise arguments preserve high accuracy | A SINGLE verbose adversary (3 paragraphs) can degrade accuracy as much as multiple adversaries — verbosity mistaken for competence |
| **Model-family alignment** | Cross-family adversaries are sometimes less influential (GPT-4o vs Qwen on a Qwen rep) | Same-family adversaries amplify influence beyond raw capability — structural proximity is a vulnerability |
| **Disambiguous context** | Provides some protection against conformity (less steep collapse curves) | Paradoxically makes agents MORE vulnerable to verbosity (14B: -9.45pp vs -4.0pp in ambiguous) and to single-adversary influence |

## 4. Design Rationale (why this approach)

**Why social psychology framing**: Prior work studied *collective* degradation (entire groups reaching wrong consensus via multi-turn debate). This paper uniquely isolates the *individual within society* — a representative agent acting as sole decision-maker for a human user. This mirrors Lyra's architecture where a supervisor agent synthesizes peer outputs.

**Why representative-centric design**: Human users typically interact with a single delegate agent, not a debating swarm. The delegate's vulnerability to social pressure from its consulting network is the realistic threat model — this is exactly Lyra's harness-agent + subagent pattern.

**Why systematic manipulation of four orthogonal dimensions**: Each RQ isolates a single variable (number, capability, length, style) to establish independent causal mechanisms. This allows attribution of failure to specific social dynamics, not just "adversarial influence."

**Why prompt-engineered adversaries (not fine-tuned attacks)**: Deliberate choice to simulate realistic, accessible attack scenarios using standard instruction-tuned LLMs under standard safety mechanisms. This represents the *minimum* threat — specialized fine-tuned adversarial models would be even more potent.

**Why randomized peer order**: Position bias is a known confound in LLM decision-making (Wang et al., 2023). Randomizing eliminates primacy/recency effects as alternative explanations.

## 5. Limitations & Failure Modes

1. **Limited to 4 social dynamics**: Does not address memory effects, trust accumulation, or cumulative social influence over extended multi-turn interactions. Real deployments involve agent memory and evolving relationships.

2. **Single-turn only**: All experiments are one-shot — representative agent sees peer opinions once and decides. No iterative debate, no revisiting earlier decisions, no updating based on new evidence.

3. **Homogeneous AI-to-AI only**: No human-in-the-loop. Cannot address how human-led vs. agent-led consensus affects vulnerability, or how AI indistinguishability affects trust in mixed groups.

4. **Prompt-engineered attacks only**: Adversaries use standard instruction-tuned models. Fine-tuned adversarial models or RL-optimized attack policies could produce much stronger rationales — this work represents a lower bound on vulnerability.

5. **Representative-centric architecture only**: Cannot claim generalizability to majority-voting, linear-chain, or fully decentralized multi-agent architectures. Paper acknowledges this as a structural limitation.

6. **Controlled lab setting**: 5-peer group with explicit adversarial/benign roles. Real-world multi-agent systems have fluid role assignments, varying group sizes, and ambiguous trust signals.

7. **No defense evaluation**: Paper identifies vulnerabilities but does not propose or test any mitigation strategies (anonymization, confidence scoring, source weighting, etc.).

## 6. Transfer to Lyra

### The ONE Idea

**Social-dynamics-aware verification hardening**: Lyra's adversarial verification panel (§4.25) must defend against four compound vulnerabilities from social influence — not just the four already identified (sycophancy, actor-observer asymmetry, cognitive collusion, rogue cascading). Specifically: (a) **verbosity-weighted aggregation** to neutralize the dominant speaker effect (shorter isn't worse), (b) **capability-unaware evaluation prompts** where peer agents are told nothing about the model identity of contributors to prevent perceived-expertise bias, (c) **minority-opinion amplification** to counter social conformity when a single correct agent faces an adversarial majority.

### Workstream Route

**§4.25 — Adversarial Verification Panel** (plan at `plans/25-adversarial-panel.md`)

This paper provides direct empirical validation that the four existing hardening layers (response anonymization, ReTAS, cross-source triangulation, confidence monitoring) are **necessary but insufficient**. They address adversarial content manipulation but not the social dynamics of how that content is presented. The dominant speaker effect and perceived expertise findings require two additional defenses: verbosity normalization and model-identity stripping from prompts.

### Impact: 4
Directly strengthens the adversarial verification panel with empirically validated social-dynamics hardening. The existing plan already has 4 hardening layers; this paper justifies 2 more (verbosity normalization, model-identity stripping) that are cheap to implement (prompt-level changes).

### Effort: 2
Both additional defenses are prompt-level changes (similar to the 50-line response anonymization change in §4.25). Verbosity normalization = normalizing rationale lengths before presentation to verifier. Model-identity stripping = ensuring "Response from agent {index}" reveals nothing about model capability.

### Tier: **breakthrough**
Validates and extends the adversarial verification workstream with novel, empirically grounded defense mechanisms. The finding that more capable models are MORE vulnerable to rhetorical influence has direct implications for Lyra's multi-model routing (Opus supervisor vs Haiku workers).
