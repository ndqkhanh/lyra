## 1. Mechanism (step-by-step, with equations/algorithms)

EvoQuality is a fully self-supervised framework that enables a VLM to iteratively refine its image quality assessment (IQA) capability without any ground-truth labels. It operates in a two-stage loop (Algorithm 1) for up to T rounds (T=2 in practice).

### Stage 1: Offline Pseudo-Label Generation via Pairwise Majority Voting

1. **Input**: A batch of N unlabeled images {x1, ..., xN}. Randomly construct M' image pairs P = {(xi, xj), ...}. In practice, 20,000 pairs are constructed per round.

2. **Self-Consistent Voting**: For each pair (xi, xj), the current VLM policy πθ is queried K=32 times with a comparative prompt `ccompare`:
   - *"Compare the two images and decide which one has better perceptual quality. Answer strictly with the index of the better image: 0 if the first image is better, or 1 if the second image is better."*
   - To mitigate positional bias, image order is randomly permuted across queries.
   - Each response includes a reasoning chain in `<think>...</think>` tags, with the final answer in `\boxed{}`.

3. **Majority Voting** (Equation 1): The pseudo-label p*(xi, xj) is defined as:
   - 1 if image xi receives more votes than xj (Kx > Ky)
   - 0 if xj receives more votes (Kx < Ky)
   - 0.5 in case of a tie (Kx = Ky)

4. **Output**: A set of high-confidence pairwise pseudo-labels that serve as "ground truth" for the subsequent online stage. Critically, these are NOT converted into absolute scores — the pairwise preference structure is preserved.

### Stage 2: Online Policy Evolution with Fidelity Rewards (GRPO)

1. **Score Generation**: For each image xi in the offline comparison set, the policy πθ_old is queried K=32 times with a direct estimation prompt `cscore`:
   - *"What is your overall rating on the quality of this picture? The rating should be a float between 1 and 5, rounded to two decimal places."*
   - Produces K reasoning trajectories and corresponding quality score vectors q(xi) = [q1(xi), ..., qK(xi)]^T.

2. **Comparative Probability via Thurstone Model** (Equation 2): For each pair (xi, xj) evaluated offline, the model's predicted probability that xi is better than xj is computed as:
   ```
   pk(xi, xj) = Φ( (qk(xi) - μ(q(xj))) / sqrt(σ²(q(xi)) + σ²(q(xj)) + γ) )
   ```
   where Φ is the standard Gaussian CDF, μ and σ² are the mean and variance of quality predictions for the image, and γ is a small constant to prevent division by zero.

3. **Fidelity Reward** (Equation 3): For each image xi and its k-th sample, the reward is:
   ```
   rk(xi) = (1/|Pi|) * Σ_{j∈Pi} [ sqrt(p*(xi,xj) * pk(xi,xj)) + sqrt((1-p*(xi,xj)) * (1-pk(xi,xj))) ]
   ```
   where Pi is the set of images paired with xi in the offline stage. This Bhattacharyya-coefficient-style fidelity measure rewards the model when its predicted comparative probabilities align with the pseudo-labels. The symmetry is important: rk(xj) is computed by swapping positions.

4. **Advantage Computation** (Equation 4): Rewards are standardized within each group:
   ```
   ak(xi) = (rk(xi) - μ(r(xi))) / σ(r(xi))
   ```
   This turns the fidelity reward into a relative advantage signal.

5. **GRPO Policy Update** (Equation 5): The policy is updated by minimizing:
   ```
   ℓ(θ, πref) = -(1/(BK)) * Σ_i Σ_k [ min( (πθ/πθ_old)*ak, clip(πθ/πθ_old, 1-ε, 1+ε)*ak ) - β*DKL(πθ||πref) ]
   ```
   where β=0.05 balances reward-weighted likelihood with KL regularization against the reference policy (the initial frozen model).

6. **KL Approximation** (Equation 6): Using the Schulman-style estimator:
   ```
   DKL(πθ||πref) ≈ (πref/πθ) - log(πref/πθ) - 1
   ```

7. **Iterative Refinement**: The online stage updates the entire VLM (not just a LoRA adapter). The updated policy becomes the base for the next round's offline voting, creating a virtuous cycle.

### Training Configuration
- Base model: Qwen2.5-VL-7B
- Training data: KONIQ dataset (authentic images, all ground-truth labels DISCARDED) + 10 synthetically distorted variants per image (random selection from 35 distortion types × 5 severity levels)
- Round 1: 20K authentic image pairs from KONIQ
- Round 2: Adds synthetic pairs (same reference, different distortions)
- Optimizer: AdamW with lr=3×10^-7, linear decay
- Hardware: 8× NVIDIA A100 GPUs, batch size 4/GPU (~12 hours per epoch)
- K=32 for both voting and online reward computation

## 3. Trade-offs (wins vs loses)

| **WINS** | **LOSES** |
|----------|-----------|
| Zero ground-truth labels needed — fully self-supervised IQA training, eliminating costly human MOS annotations | Underperforms supervised models on in-distribution (KONIQ: 0.835 vs. DeQA-Score 0.953) — self-evolution trades absolute accuracy for generalization |
| +31.8% average PLCC gain over base VLM across 8 diverse IQA benchmarks | Requires in-domain unlabeled image corpus — training on out-of-domain images without quality-relevant content may hurt performance |
| Outperforms ALL supervised VLM-based models on out-of-distribution generalization (WAVG 0.762 vs. 0.704) | High computational cost: 12 hours/epoch on 8×A100, K=32 forward passes per pair (voting) + K=32 per image (online) |
| Progressive refinement across rounds without catastrophic forgetting | Second-round gains marginal on authentic datasets — only synthetic distortion benchmarks see meaningful Round 2 improvements |
| Stackable: can augment existing supervised IQA models for better OOD generalization | Voting with K=32 per pair means O(N_pairs × K) inference cost — scales poorly with dataset size |
| Ranking-based reward signal (fidelity) enables continued improvement; regression-based (EvoEstimate) stalls after Round 1 | Positional bias mitigation via random permutation is heuristic, not guaranteed — some bias may persist |
| No distortion-type labels needed — synthetic augmentation done blindly | Effectiveness depends on model-internal quality "wisdom of crowd" — if the base model has poor initial IQA, voting may produce noisy pseudo-labels |

## 4. Design Rationale (why this approach)

1. **Why self-consistency + majority voting**: The core insight is that correct quality judgments emerge consistently across diverse reasoning traces, while incorrect ones are sporadic. This "wisdom of the crowd" within a single model (Wang et al., 2022) provides a free supervisory signal. Previous work (TTRL, MM-UPT) applied this to discrete reasoning (math, geometry); EvoQuality adapts it to the continuous, subjective domain of IQA.

2. **Why pairwise voting rather than direct score averaging**: IQA is inherently relative, not absolute. Human perception compares images; there is no "true score" for an image in isolation. Pairwise comparisons preserve this relational structure. EvoEstimate ablation (Table 5) confirms that averaging scores into pseudo-labels produces a weaker signal that stops improving after Round 1.

3. **Why fidelity reward + Thurstone model**: The fidelity measure (Bhattacharyya coefficient between pseudo-label and predicted probability) is a principled information-theoretic quantity that provides smooth gradients. The Thurstone model maps continuous score predictions to comparative probabilities via the Gaussian CDF, naturally handling the variance in quality estimates — a key advantage over direct score regression which ignores uncertainty.

4. **Why GRPO (not PPO or DPO)**: GRPO eliminates the need for a separate value/critic network by standardizing rewards within each group. This is computationally lighter than PPO and better suited for the pairwise structure where "absolute" reward magnitude is less meaningful than relative ranking.

5. **Why entire VLM fine-tuning (not LoRA)**: Full parameter updates allow the model to fundamentally restructure its perceptual features. The KL penalty against the frozen reference prevents catastrophic drift.

## 5. Limitations & Failure Modes

1. **Dependency on in-domain unlabeled corpus**: The framework requires a pool of unlabeled images relevant to the target domain. If images lack meaningful quality variation (e.g., all high-quality), pairwise voting degenerates to random noise. Performance on out-of-domain content with no quality-relevant training images is unverified.

2. **Computational overhead**: Each round requires ~12 hours on 8×A100 GPUs. The K=32 sampling budget means 32 forward passes per image pair in offline voting AND 32 per image in online training. Scaling to larger datasets or more rounds is expensive.

3. **In-distribution performance gap**: EvoQuality trails supervised methods on KONIQ (0.835 vs 0.953 DeQA-Score) — the self-evolution process cannot fully compensate for missing ground truth on the training distribution itself.

4. **Diminishing returns on authentic distortions**: Round 2 improvements are concentrated on synthetic distortion datasets (TID2013, PIPAL, KADID). Authentic distortion benchmarks (KONIQ, SPAQ, LIVEW) show marginal or no improvement in Round 2.

5. **Base model quality floor**: The method fundamentally relies on the base VLM having non-trivial IQA capability. If the model's initial quality judgments are poor, majority voting over poor judgments still yields poor pseudo-labels. The paper does not test on models with weak initial IQA.

6. **Positional bias mitigation is heuristic**: Random permutation of image order helps but does not guarantee elimination of positional preference bias, which is a known issue in VLM pairwise comparisons.

7. **Limited to IQA domain**: The framework assumes a relative-comparison-based task structure. Extension to other perceptual tasks (aesthetics, realism evaluation) is hypothesized but not tested.

## 6. Transfer to Lyra (the one idea + §4.x workstream + Impact/Effort/Tier)

### THE ONE TRANSFERABLE IDEA

**Self-consistency voting for pseudo-label generation as a self-supervised reward signal for RL-based agent fine-tuning.**

In Lyra's context: Instead of relying on expensive human annotations or external verifiers to train Lyra's quality-evaluation or ranking subsystems, Lyra could use its own multiple reasoning traces (via varied prompts, temperatures, or chain-of-thought paths) to generate pseudo-labels via majority voting. These self-consensus labels would then serve as fidelity rewards in a GRPO-style policy update loop, enabling Lyra to self-improve on subjective/perceptual tasks (e.g., response quality ranking, hallucination detection confidence, code-review severity assessment) without ground-truth labels.

The key mechanism to port: **(a)** Prompt the model K times with the same input, **(b)** aggregate via majority voting to produce high-confidence pseudo-labels, **(c)** define a fidelity reward that measures alignment between the model's predicted probability distribution and the pseudo-label consensus, **(d)** update via GRPO with KL regularization to prevent drift.

### Workstream Route: §4.5 (Self-Improvement / Autonomous Refinement)

This directly feeds Lyra's capability for autonomous quality improvement without human supervision — specifically the "evaluator self-training" and "reward model bootstrapping" sub-streams.

### Impact: 4
Pseudo-label generation via self-consistency is broadly applicable to Lyra's ranking and evaluation subsystems. The mechanism is proven at ICLR 2026 level. Could substantially reduce reliance on human eval data for Lyra's judgment-oriented capabilities.

### Effort: 4
Requires: (1) implementing K-sample voting infrastructure, (2) adapting the fidelity reward function to Lyra's task structure, (3) integrating GRPO training loop with Lyra's policy, (4) careful KL regularization tuning, (5) evaluation on Lyra-specific benchmarks. Not a weekend project but well-scoped.

### Tier: **breakthrough**
Self-evolving evaluation capability without human labels is a paradigm shift for agent quality. If Lyra can self-improve its judgment (of code quality, response ranking, hallucination detection) through internal consensus, it unlocks continuous autonomous improvement — directly aligned with Lyra's §4 mission of building a self-improving agent.
