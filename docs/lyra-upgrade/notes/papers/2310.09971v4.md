## 1. Mechanism (step-by-step)

AMAGO is an off-policy in-context RL agent that trains a single shared Transformer to simultaneously serve as actor, critic, and trajectory encoder across entire rollouts.

### Step 1: Unified Goal-Conditioned CMDP Format
Every environment is cast to a unified input tuple at each timestep t:
```
τ_t = (obs_t, action_{t-1}, reward_t, reset_t, goal_embedding, time_t)
```
A **timestep encoder** (MLP) maps each timestep to a fixed-size representation. This is the only architecture change needed across domains.

### Step 2: Single Shared Transformer Trajectory Encoder
A causal Transformer processes sequences of timestep embeddings of length l (context length). Crucially:
- Actor and critic **share the same Transformer** as backbone
- **No target sequence models** (no separate target Transformer)
- All parameters updated by **one optimizer** in one forward/backward pass

### Step 3: Joint Actor-Critic Loss
The loss is computed across ALL timesteps in parallel (unlike RNN methods that process sequentially):

```
L_AMAGO = E_{τ~D}[ (1/l) * Σ_{t=0}^{l} (λ₀·L_TD(st,at,rt,st+1) + λ₁·L_PG(st) + λ₂·L_FBC(st,at)) ]
```

Where:
- **L_TD** (Eq.2): Standard 1-step TD error with clipped double-Q. `L_TD(s,a,r,s') = [Q(s,a) - (r + γ·stopgrad(Q̄(s',π̄(s'))))]²`
- **L_PG** (Eq.1): Policy gradient. `L_PG(s) = -Q(stopgrad(s), π(s))`
- **L_FBC** (Eq.6): Filtered behavioral cloning. `L_FBC(s,a) = -1{A(s,a)>0} · log π(a|s)` where A(s,a) = Q(s,a) - E_{a'~π(s)}[Q(s,a')]

**Key stability detail:** The critic's gradients are **detached** from the actor loss L_PG to prevent the critic from being pulled toward maximizing Q through the shared backbone (Appendix A.1, Eq.3).

### Step 4: PopArt Normalization
PopArt (van Hasselt et al., 2016) normalizes Q-value outputs so that L_PG and L_TD stay on a predictable scale across environments. Without it, gradient norms become destructively large and rely on extreme clipping. Default weights (λ₀=10, λ₁=1, λ₂=0.1) work across environments (Fig. 11).

### Step 5: Multi-Gamma Learning
Q-values are computed in parallel for γ ∈ {.7, .9, .93, .95, .98, .99, .992, .994, .995, .997, .998, .999, .9991, ..., .9995} (discrete) or {.9, .95, .99, .993, .996, .999} (continuous). Each γ creates its own Q-value surface. At test time, γ=.999 is selected. The cost is low relative to Transformer size (Fig. 12).

### Step 6: REDQ Critic Ensembling
Uses 4 parallel critics, with the minimum of 2 used for TD targets (clipped double-Q). This handles high replay ratios from long-sequence training.

### Step 7: Stabilized Transformer Architecture
Standard Pre-LN Transformers collapse in long RL training runs due to **attention entropy collapse**. AMAGO applies three fixes:
1. **Leaky ReLU** replaces all ReLU/GeLU (in residual blocks and actor/critic MLPs) to prevent gradient death
2. **Normformer-style extra LayerNorms** isolate Q/K/V saturation
3. **σReparam** limits Q/K/V magnitudes: `W = σ(W_raw) · W_raw` constrains linear layer outputs
Plus Flash Attention for GPU memory efficiency at long contexts.

### Step 8: Hindsight Instruction Relabeling (Goal-Conditioned Extension)
For multi-goal domains (Algorithm 1):
1. Record which alternative goals were achieved during rollout
2. For a trajectory that completed n of k assigned goals, sample h ∈ [0, k-n] alternative goals
3. Insert alternatives chronologically into the original instruction
4. Recompute rewards for the new instruction (return = n+h for binary rewards)
5. **Goal Importance Sampling:** Prioritize rare goals during relabeling to focus learning on frontier skills

### Step 9: Exploration Noise
ε anneals within each rollout (not just across training). The schedule intensity decreases over training and is randomized across parallel actors, removing the need for tuning.

## 2. Results (with real benchmark numbers)

### POPGym Suite (39 environments)
- **Standardized mean score:** 0.95 (relative to [0,1] range defined by best/worst baseline)
- **9 recall-intensive environments:** AMAGO 0.999 vs GRU baseline 0.19
- **Naive shared Transformer baseline collapses in 9/39 environments;** AMAGO stable in all 120+ trials
- 256-dim model, 3 Transformer layers, 8 heads, 3 random seeds per env, 15M timestep limit
- Training time: ~8 hours/run on single A5000 GPU

### Passive T-Maze (Memory Isolation Test)
- **Context length l = H = 10,000:** AMAGO solves to GPU memory limit
- Previous best from concurrent work (Ni et al., 2023): l = 1,500
- GRU variants fail at l ≈ 100

### Half-Cheetah Velocity (Meta-RL, continuous actions)
- 3-episode adaptation (H=600). Matches/exceeds variBAD, BOReL, RL² baselines
- Note: Short context is sufficient here; AMAGO's long sequences don't hurt

### Dark Key-To-Door (Sparse Meta-RL)
- AMAGO solves within ~10 episodes (H=500, max 2 reward/episode, total max 20)
- Algorithm Distillation converges ~3,000-5,000 timesteps later
- AMAGO-GRU (RNN trajectory encoder) fails to make progress at l=H=500

### Meta-World ML-1 (Robotics)
- Meta-test success decreases slightly at longer context lengths (overfitting on small env distribution)
- Max meta-train performance similar across all context lengths

### Package Delivery (Sparse + Memory)
- AMAGO: ~100% success rate
- w/o Relabeling: ~0% success rate
- w/o Memory: ~10% success rate
- Multi-gamma essential (60% without it)
- "Relabel All" (GCSL-style) fails due to low TD learning signal

### MazeRunner (Goal-Conditioned Maze Navigation)
- **15×15 (H=400):** ~100% success (AMAGO), ~91% without position info
- **30×30 (H=1,000):** ~68% success (AMAGO), ~0% all baselines without relabeling
- w/o Memory: ~34% on 30×30
- With randomized action dynamics: AMAGO 68% vs RL² 6%, variBAD/HyperX ~0%

### Crafter (Procedural Open World, 22 achievements + travel goals)
- **Undirected (shaped reward):** 99.9% collect wood, 99.4% wood pickaxe, 86.3% stone pickaxe, 92.3% stone sword, 69.5% collect coal, 53.5% defeat skeleton
- **Instruction-conditioned (sparse):** 99.8% wood pickaxe, 97.8% stone sword, 90.1% collect coal, 76.5% defeat skeleton, 62.1% all random instructions
- **Pixels vs Textures:** 53.9% vs 62.1% on all random instructions
- **All agents hit 0% on collect iron/diamond** — exploration barrier remains
- Goal importance sampling shortens plateaus but converges to same final performance

### Training Throughput (Fig 29)
- AMAGO 1.2M params (128d×1 layer): ~35 grad steps/sec at l=64, ~10 at l=1024, ~2 at l=8000 (A5000)
- Separated RNN 700k params: higher throughput at short contexts, worse scaling
- Flash Attention provides 2-3× speedup at long contexts

## 3. Trade-offs

| Win | Lose |
|------|------|
| SOTA on 39 POPGym environments with zero per-env tuning | Slower than RNNs at context lengths < 512 (Fig 29) |
| Single Transformer = single forward/backward pass per update | Multi-gamma inflates critic output heads (γ_N × larger) |
| No target sequence models → architectural simplicity | Can overfit on small environment distributions with long contexts |
| Relabeling makes exploration of sparse goals tractable | "Relabel All" (every trajectory → success) kills TD learning signal |
| Stable at l=H=10,000 (GPU memory limited, not stability limited) | Does NOT solve credit assignment (Active T-Maze unsolved) |
| PopArt eliminates reward-scale hyperparameter tuning | PopArt adds compute overhead in value normalization |
| Filtered BC provides supervised learning-like signal | Filtered BC can conflict with multi-gamma; increases policy entropy |
| Shared model = lower deploy complexity | RNNs more sample-efficient at short sequences (H=75 Wind env) |
| Instruction relabeling discovers exploration curricula automatically | Cannot complete Crafter's full tech tree (iron/diamond unsolved) |

## 4. Design Rationale

The authors argue that "off-policy in-context RL combines two of the most implementation-dependent areas" in deep RL, and previous Transformer-in-RL attempts fail because they either (a) reformulate RL as supervised learning to avoid instability, or (b) use separated actor/critic Transformers that multiply compute cost. AMAGO's design is driven by the observation that a **shared Transformer architecture** is only unstable because the critic receives gradients from the actor's objective through the shared backbone. The detach trick (A.1) solves this. Multi-gamma is motivated by: "it is less likely that all of our loss terms have converged" when training with parallel γ values, ensuring the shared Transformer always has a meaningful learning signal. The Transformer architectural modifications (Normformer + σReparam + Leaky ReLU) address attention entropy collapse — a specific failure mode where RL policies converge on precise, low-entropy attention patterns (Fig 15) that saturate activations. Goal importance sampling by rarity is preferred over domain-specific heuristics because it generalizes across domains without tuning.

## 5. Limitations & Failure Modes

1. **Exploration ceiling:** Crafter agents plateau at iron/diamond (0% success). Neither tech-tree bias nor expanded goal spaces solve this. The multi-goal relabeling exploration mechanism depends on already having discovered prerequisite skills.
2. **Credit assignment decoupled from memory:** The Passive T-Maze is solved to l=10,000 (pure recall), but the "Active T-Maze" — which requires credit assignment — is NOT improved by Transformers. Memory and credit assignment are separate problems.
3. **Short-context inefficiency:** RNNs are more sample-efficient than Transformers at H=75 (Wind environment). Transformers only pull ahead at longer contexts.
4. **Overfitting risk:** Meta-World ML-1 shows declining meta-test success with longer context lengths on small env distributions.
5. **Sample efficiency not optimized:** Learning curves still improving at 15M timesteps in POPGym. Multi-gamma defaults likely suboptimal — including low γ values (.1, .05) may improve sample efficiency (Fig 18).
6. **Compute:** Each trial needs one A5000 GPU. POPGym suite took 8 hrs/run. Relabeling creates very high effective replay ratios.
7. **Multi-task reward normalization:** Meta-World ML-10/ML-45 results are bottlenecked by per-task reward scale differences, not by adaptation ability. PopArt helps but is insufficient for widely-varying reward magnitudes.
8. **"Relabel All" failure:** Supervised-sequence-modeling-style relabeling (akin to Decision Transformer/GCSL) fails because every trajectory always appears successful, destroying TD learning signal (Sec C.3.2).

## 6. Transfer to Lyra

### The ONE Transferable Idea
**Single shared sequence model with gradient-isolated actor-critic heads.** AMAGO proves that a single Transformer can simultaneously serve as state estimator, policy network, and value function — provided (a) the critic's gradients are detached from the actor's loss path through the shared backbone, and (b) Q-value scales are normalized (PopArt). For Lyra, this means the agent's context/memory encoder (LTM system) could be a single Transformer that feeds both:

- A **prediction head** (analogous to the critic — estimating expected future outcomes)
- An **agency head** (analogous to the actor — producing tool calls, responses, reasoning traces)

The gradient isolation trick prevents destructive interference between these two objectives while keeping a unified internal representation. This eliminates the need for separate memory retrieval and planning networks.

The **multi-gamma technique** adds an orthogonal benefit: by training value estimates for many horizons simultaneously, the shared representation is forced to encode both short-term reactivity and long-term planning — directly relevant to Lyra's need to balance immediate tool-use with session-level goal pursuit.
