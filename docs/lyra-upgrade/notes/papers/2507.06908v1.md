## 1. Mechanism (Step-by-Step)

MI N D is a training-free, gradient-free multi-agent framework operating over an **unannotated reference set** S_ref for zero-shot harmful meme classification. Each meme M = {V (visual), T (text)}. The framework has three sequential stages:

### Stage 1: Similar Sample Retrieval (SSR)

**Purpose:** Find K contextually similar memes from the unlabeled reference pool to ground analysis.

1. **Multimodal embedding** (Equation 1): For each meme in both S_test and S_ref, compute a fused embedding:
   ```
   E = λ_v · V_enc(V) + λ_t · T_enc(T)
   ```
   where V_enc and T_enc are CLIP/ViT-based visual and textual encoders, and λ_v, λ_t are fixed modality fusion weights.

2. **Cosine similarity matching** (Equations 2-3): For each target sample, compute:
   ```
   s = sim(E_target, E_ref) = (E_target · E_ref) / (||E_target|| · ||E_ref||)
   ```
   Producing a similarity vector S ∈ R^N for all N reference samples.

3. **Top-K selection** (Equation 4): M_similar = {M_ref | s ∈ TopK(S)}. Default K=3, chosen as optimal balance (Figure 4).

### Stage 2: Relevant Insight Derivation (RID)

**Purpose:** Derive high-level harm assessment rules from similar memes through bidirectional iterative processing, without requiring ground-truth labels.

An LMM agent (LMM_deriving) equipped with a Chain-of-Thought deriving prompt P_deriving processes K similar memes. The prompt (Figure 10) instructs the agent to synthesize "GENERAL and HIGH LEVEL" rules (max 5) about harmfulness, iteratively adding, editing, or removing rules based on each meme examined.

**Forward Pass** (Equation 5):
```
I_fwd,i = LMM_deriving(M_similar,i, I_fwd,i-1, P_deriving)   for i = 1..K
```
Starts with M_1 through M_K, accumulating insights cumulatively. Each step feeds prior insights as context.

**Backward Pass** (Equation 6):
```
I_back,i = LMM_deriving(M_similar,K+1-i, I_back,i-1, P_deriving)   for i = 1..K
```
Processes memes in reverse order (M_K through M_1). This compensates for sequential bias where earlier memes receive more refinement attention in the forward pass.

**Output:** Two independent insight sets I_fwd,K and I_back,K, each containing ≤5 high-level harm assessment rules derived from complementary sequence perspectives.

### Stage 3: Insight-Augmented Inference (IAI)

**Purpose:** Produce a robust final harmfulness judgment through multi-agent debate with arbitration.

1. **Debater agents** (Equations 7-8): Two independent LMM_debater instances each receive one insight set (forward or backward) plus the target meme:
   ```
   J_fwd = LMM_debater(I_fwd,K, V_target, T_target)
   J_back = LMM_debater(I_back,K, V_target, T_target)
   ```
   Each outputs: `Thought: [analysis weighing insight note against own assessment]` + `Answer: [harmful/harmless]`

2. **Consensus or Arbitration** (Equation 9):
   ```
   if J_fwd == J_back:
       J_final = J_fwd                     // consensus: direct adoption
   else:
       J_final = LMM_judge(J_fwd, J_back, V_target, T_target)  // judge arbitrates
   ```
   The judge examines both debaters' reasoning chains and the target meme to resolve disagreement through reasoned arbitration.

**Backbone model:** LLaVA-1.5-13B as default for all agents (deriving, debater × 2, judge); also tested with LLaVA-1.5-7B, LLaVA-1.6-34B, and Gemini-1.5-Flash.

## 2. Results (Benchmark Numbers)

**Setup:** 3 datasets — HarM (COVID-19 memes), FHM (Facebook Hateful Memes), MAMI (misogyny memes). Zero-shot (no labels). Metrics: Accuracy and Macro-F1. Hardware: 4× NVIDIA A40 48GiB.

**Key:** MI N D (13B) surpasses LLaVA-1.6-34B on HarM by +3.60 Macro-F1 and surpasses GPT-4o by +4.90 Macro-F1 on HarM.

## 3. Trade-offs (Wins vs Loses)

| Win | Lose |
|-----|------|
| **Zero-shot** — no annotated training data needed at all | **~8x inference overhead** vs simple zero-shot baselines (9h on MAMI with LLaVA-1.5-13B) |
| **Outperforms GPT-4o** (+4.90 F1 on HarM) with 13B open model | **Retrieval quality dependence** — if SSR fails to find truly relevant memes, downstream stages amplify noise |
| **Generalizes across model scales** — 7B→13B→34B, open & closed source | **No cross-modal weighting** — uniform treatment of all retrieved memes regardless of relevance degree |
| **Beats few-shot** — MIND zero-shot > 3-shot+SSR by +5.59 F1 on HarM | **Irony/satire blind spot** — over-reliance on literal text meaning; masked harmful intent gets missed |
| **Training-free** — no gradient updates, no weight modification | **False positive risk** — over-sensitivity to historical figures/symbols leads to overcautious classifications |
| **Interpretable** — outputs explicit reasoning chains | **Consensus bias** — debate mechanism prioritizes agreement over verification of reasoning quality |
| **Flexible efficiency** — unidirectional RID halves calls | **Cultural knowledge dependency** — relies on base LMM's understanding of social/cultural nuance |

## 4. Design Rationale

**Why retrieval instead of classification?** Memes evolve rapidly — new formats emerge faster than annotation pipelines can track. The core insight: despite surface-level evolution, harmful memes retain identifiable cross-domain patterns. Retrieval from an unlabeled pool surfaces these patterns without requiring new labels.

**Why bidirectional insight derivation?** Sequential processing introduces position bias — earlier items receive more accumulated-context refinement. The backward pass compensates by approaching from the opposite direction, ensuring each of the K retrieved memes contributes approximately equally to the final insight set.

**Why multi-agent debate + judge?** Single-agent judgments are vulnerable to reasoning blind spots and overconfidence. Two independent perspectives (forward/backward insights) surface potential disagreement. Rather than simple majority voting, the judge agent examines both reasoning chains — a meta-level evaluation that filters weak arguments rather than averaging opinions.

**Why training-free?** Enables immediate deployment on new meme formats without data collection delays. The open-source LLaVA backbone ensures full reproducibility, in contrast to closed-source models whose training data and update schedules are opaque.

## 5. Limitations & Failure Modes

1. **Retrieval sensitivity:** Embedding-based cosine similarity may not capture deep semantic/conceptual relationships in highly novel meme formats. Random retrieval degrades F1 by up to 4.27%.

2. **Uniform meme weighting:** All K retrieved memes are treated equally in insight derivation, regardless of their actual relevance to the target. A relevance-weighted mechanism could produce more refined insights.

3. **Consensus-over-quality:** The debate mechanism evaluates agreement but does not quantitatively assess the quality or reliability of derived insights. Correct conclusions can emerge from flawed reasoning chains, and the framework cannot detect this.

4. **~8x computational overhead:** Requires K×2 deriving calls, 2 debater calls, plus potential judge call per sample. Unidirectional RID halves this at moderate performance cost.

5. **Irony and satire failure:** The framework over-relies on literal text semantics. Harmful memes using ironic juxtaposition (peaceful text + violent imagery) are frequently misclassified as harmless (Figure 6b).

6. **Over-caution on historical/cultural content:** Images containing recognizable historical figures trigger overcautious harmful classification even when the accompanying text is innocuous (Figure 6a).

7. **Cultural knowledge dependency:** Final performance is bounded by the base LMM's grasp of social and cultural nuance, limiting detection of subtly encoded harm requiring deep domain knowledge.

## 6. Transfer to Lyra

**The One Idea:** The bidirectional insight derivation + debate-with-judge-arbitration pattern is a generalizable safety evaluation architecture. Two agents independently analyze the same content from complementary perspectives (forward/backward, optimistic/skeptical, text-focused/image-focused), derive structured insight sets, then a third agent adjudicates disagreements by examining reasoning quality rather than voting. This pattern transcends meme classification — it applies to any LLM output evaluation where single-pass judgment is unreliable.

**Workstream Route:** §4.7 (Safety & Alignment) — this directly feeds Lyra's guardrail and content moderation subsystem. Could also enrich §4.5 (Agent Architecture) as a reusable multi-perspective reasoning pattern for Lyra's internal agent orchestration.

**Impact:** 4 — The debate+judge architecture is a proven reliability boost (+4-14% F1 depending on base model quality) applicable to Lyra's output moderation and self-critique flows. Training-free nature means zero annotation cost.

**Effort:** 3 — Requires: (1) implementing the SSR pipeline with Lyra's embedding infrastructure, (2) authoring insight-derivation and debate prompts tuned to Lyra's content domains, (3) integrating 3-4 agent calls per decision into the Lyra agent orchestration layer. The core algorithms (cosine retrieval, Top-K, sequential prompt chaining) are straightforward.

**Tier:** **Investigate** — The pattern is powerful but the domain (social media meme detection) differs from Lyra's primary use case. Worth prototyping the debate+judge pattern in Lyra's safety evaluation pipeline. The ~8x latency overhead is a practical deployment consideration; unidirectional RID provides a lower-cost entry point for initial evaluation.
