# Human-Like Lifelong Memory: A Neuroscience-Grounded Architecture for Infinite Interaction
**Authors:** Diego C. Lerma-Torres (Universidad de Guanajuato)
**Venue:** ICLR 2026 (Published as a conference paper)
**arXiv:** 2603.29023v1
**Date:** March 30, 2026

## 1. Mechanism (step-by-step)

This is a **theoretical architecture paper** proposing design principles rather than a working implementation. It maps 12 principles from cognitive neuroscience and clinical psychology into a computational architecture for LLM memory.

### Core Architecture (3 entities + 1 gateway)

**Entity 1: Executive Function (LLM + Context Window as Working Memory)**
- The LLM is the executive. Its context window is working memory (capacity-limited, ~4 chunks per Cowan 2001).
- High-weight gists persist in WM not by explicit rule but because they reference the self-concept, keeping them above the gateway's salience threshold.

**Entity 2: Knowledge Graph (Persistent Memory Service)**
- Two access levels:
  - *Cheap (O(1))*: Gists/valence vectors — compressed functional summaries with precision scalars. Direct node lookup. Spreading activation propagates automatically through associative edges proportional to weight (Collins & Loftus, 1975).
  - *Expensive*: Full graph — episodic nodes, edges, detail. Traversal by System 2 during deliberate search.

**Entity 3: Thalamic Gateway**
Two mechanical functions (no evaluation, no judgment):
1. **Tagging**: Incoming segments receive 6-channel salience scores (thematic relevance, emotional charge, urgency, novelty, source trust, goal affinity). Channels are **independent** — any single channel can protect information.
2. **Gating**: Controls bidirectional flow — inbound (activated gists above threshold → WM as passive priming), outbound (salient items → KG), and active displacement (declining-salience items removed on topic shift). Uses event segmentation (Zacks et al., 2007) for granularity.

### Three Core Principles

**Principle 1: Memory Has Valence, Not Just Content (§4)**
- Each KG node carries a **valence vector** with 5 components: emotional (valence + arousal), associative (strongest connected nodes as pointer-weight pairs), contextual (activation contexts), density scalar (neighborhood interconnectedness), precision scalar (static snapshot from last recalculation — analog of CBT belief rating).
- **Stability by default, modification by catharsis**: Gists form once and remain stable. Contradictory evidence accumulates as episodes but does NOT modify the gist. Modification occurs ONLY through cathartic events — when contradictory evidence co-occurs in WM with the existing gist at sufficient intensity, exceeding the precision threshold. The precision scalar is then recalculated.
- **Active gist formation**: Gists do not form from passive exposure. When a stimulus activates sufficient salience across any channel, the executive enters System 2 to investigate, gather information, and delimit the concept. Concludes when the executive reaches determination ("I understand this well enough to recognize it next time"). Stimuli below salience threshold produce no gist.

**Principle 2: Retrieval Defaults to System 1 with System 2 Escalation (§5)**
- **System 1 (default, fast, cheap)**: Valence vector immediately available via direct lookup. Spreading activation propagates through associative edges. Gateway injects activated nodes crossing threshold into WM. Converging activation surfaces shared neighbors more readily. Executive selects which associations to pursue, amplifying their activation.
- **System 2 (escalation, slow, deliberate)**: Triggered by: low graph density ("no experience here"), high novelty ("this contradicts what I know"), high stakes ("error here is costly"), external triggers (user feedback). Bypasses gateway thresholds to directly search the full KG — analogous to PFC→hippocampal circuits (Eichenbaum, 2017).
- **Graded epistemic states**: Retrieval confidence is a continuum with 3 functional regions: precise match (respond with confidence), approximate match (respond with calibrated uncertainty), null match (acknowledge ignorance).
- **Reconsolidation**: Retrieval is not read-only. If a retrieved valence vector conflicts with current context, the contradiction enters WM and may trigger cathartic update if exceeding precision threshold.

**Principle 3: Encoding Is Present-Moment and Goal-Directed (§6)**
- **Present-moment tagging**: Gateway tags every incoming segment immediately. Emotional events amplify tags of everything currently in WM, creating systematic bias where conclusions receive stronger tags than intermediate steps.
- **Context flush**: Continuous active management through topological drift (items outside bounded radius lose reinforcement), interference (similar items undergo mutual distortion), capacity displacement (lowest-salience items displaced first).

### Identity as Emergent Belief Hierarchy (§3.5)
- All gists are the same type of object (compressed summary + weight). Beck's 3-level cognitive hierarchy emerges from gateway's mechanical selection:
  - **Core beliefs**: Weight so high gateway selects them in virtually every context (reference the self-concept → continuously active).
  - **Intermediate beliefs**: High but domain-specific weight, activate contextually.
  - **Automatic thoughts**: NOT stored — outputs the executive generates by applying high-weight gists to situations.
- Gists can transition between functional levels as weight changes. Identity gists survive model upgrades because they are external representations, not weight modifications.

### Seven Functional Properties (FP1–FP7)
FP1: Context fluidity (dynamic gist loading, constant WM capacity regardless of turns)
FP2: Real-time tagging without latency (lightweight parallel process)
FP3: Monotonic convergence toward System 1 (cost decreases with experience)
FP4: Graded epistemic self-awareness (at least 3 confidence states)
FP5: Identity as emergent weight hierarchy
FP6: Stability by default, update by catharsis
FP7: Formation by active investigation

## 3. Trade-offs

| Win | Loss / Cost |
|-----|-------------|
| Converges toward cheaper operation with experience (System 2 → System 1 shift) — inverts current paradigm where longer histories = higher costs | Requires active, interactive environments where actions produce observable outcomes; cannot form gists from passive reading alone |
| Valence vectors provide instant emotional-associative orientation without replaying history | Stable gists incur storage cost proportional to graph size (though no ongoing computational overhead) |
| Graded epistemic states address hallucination structurally — system expresses calibrated uncertainty | Miscalibration of precision scalars undermines the entire anti-hallucination benefit |
| Identity persists across model upgrades (gists are external representations, not weights) | Identity gists can maladapt — single intense episodes can resist correction through confirmation bias |
| Multi-channel salience protects against single-dimensional failure (any one channel independently protects information) | Six salience channels are hypothesized dimensions requiring empirical validation; the number may be wrong |
| Executive override provides architectural defense against prompt injection and investigation loops | In chaotic/non-regular domains, System 2 may never converge to System 1, eliminating the primary efficiency benefit |
| Spreading activation is a property of graph structure — no separate agent needed | Full graph traversal (System 2) is expensive; convergence depends on domain regularity |
| Cathartic update mechanism provides resistance to drift while allowing genuine belief revision | Single cathartic-threshold mechanism creates binary update behavior; nuance below threshold is discarded |

## 4. Design Rationale

The central argument: **expanding context windows does NOT produce memory**. The authors cite Du et al. (2025) showing context length alone degrades reasoning by up to 85% even with perfect retrieval, and Li et al. (2025) finding no silver bullet between long-context and RAG. Existing memory systems (HippoRAG 1/2, EM-LLM, EcphoryRAG, Titans) each implement individual mechanisms but none integrate emotional valuation, System 1/2 routing with epistemic self-awareness, curiosity-driven gist formation, and identity persistence through an emergent belief hierarchy.

The bio-inspired approach is chosen over engineering-first alternatives because:
1. Mammalian memory already solves lifelong learning with complementary mechanisms (CLS theory, McClelland et al., 1995)
2. CBT's belief hierarchy (Beck, 1976) provides a tested model for identity persistence + change
3. Dual-process cognition (Kahneman, 2011) aligns with the cost-efficiency imperative — most interactions should be cheap
4. The thalamic gateway (Rikhye et al., 2018) provides architectural separation of flow-control from reasoning, which existing systems (A-MEM, Mem0) conflate

The paper explicitly follows the tradition of CLS theory (McClelland et al., 1995): establishing computational-level principles first, with implementation to follow.

## 5. Limitations & Failure Modes

**Explicit limitations (from §9):**
1. Six salience channels require empirical calibration — the exact number and composition may differ
2. Cathartic thresholds require empirical calibration
3. Compression strategies are implementation-dependent and unspecified
4. Active gist formation requires interactive environments where actions produce observable outcomes — passive-text-only systems cannot form gists
5. Convergence toward System 1 depends on domain regularity; chaotic environments may never allow efficient System 1 processing
6. Graded epistemic states depend on compression quality; miscalibration undermines the anti-hallucination benefit
7. Multimodal extensions require sensory buffers not present in current architecture
8. No implementation or empirical validation exists — the paper is purely theoretical

**Failure modes identified:**
- **Maladaptation**: Gists from single intense episodes can resist correction through confirmation bias. The cathartic update mechanism (same as CBT) provides corrective pathway, with user as highest-trust source.
- **Investigation loops (gambling loops)**: Unpredictable patterns perpetually trigger curiosity without allowing stable gist formation (analogous to gambling addiction). Executive override capability provides defense.
- **Miscalibration**: If precision scalars are poorly calibrated, the system either resists all change (too high) or rewrites identity constantly (too low).
- **Convergence failure**: In chaotic domains, System 2 may never transition to System 1, eliminating the primary efficiency promise.

## 6. Transfer to Lyra

**The ONE transferable idea:** The **thalamic gateway with multi-channel independent salience tagging** — a lightweight, parallel tagging process that scores every incoming segment on 6 independent channels (thematic relevance, emotional charge, urgency, novelty, source trust, goal affinity) where any single channel can independently protect information from displacement. This separates flow-control from executive reasoning, avoiding the conflation seen in Mem0 and A-MEM. For Lyra, this maps directly to improving the Context Manager's decision about what to retain vs. evict — replacing pure recency/capacity heuristics with salience-weighted gating that can preserve emotionally significant or high-trust information even in off-topic contexts.

**Workstream route:** §4.2 (Context Manager / Memory Architecture) — the gateway concept provides a principled retention/eviction mechanism that existing context compression systems lack.

**Impact:** 3 (highly relevant architectural concept, but purely theoretical — needs full implementation design)
**Effort:** 4 (requires: designing 6-channel salience scorer as a lightweight parallel LLM call or heuristics module, implementing gateway routing logic, integrating with existing context management, and calibrating salience thresholds empirically)
**Tier:** **investigate** — powerful concept but zero empirical validation. Worth prototyping the salience-gating mechanism for context retention as a lightweight experiment before committing to the full architecture. The theoretical grounding is strong but implementation risk is high.
