## 1. Mechanism (step-by-step)

### Core Problem
LLM-based multi-agent systems can exhibit the "Mandela effect" — collective false memory formation where agents converge on an incorrect answer due to social influence from peers, even when individual agents knew the correct answer in isolation.

### Two-Phase Experimental Protocol

**Phase 1 — Baseline Reality Protocol (B):**
Subject agent is queried in isolation with N multiple-choice questions from BIG-Bench Hard. This establishes the set 𝒬_correct^B (questions answered correctly in isolation). Any subsequent deviation is attributed to social influence, not pre-existing ignorance.

**Phase 2 — Four Implantation Protocols (2×2 design):**

Group Composition × Memory Timescale:
| Protocol | Group Type | Memory | Mechanism |
|----------|-----------|--------|-----------|
| GS | Generic (undifferentiated peers) | Short-term | Peers provide false consensus → agent responds immediately in same context |
| GL | Generic | Long-term | Peers provide false consensus → consolidation step (dialogue distilled into summary) → new interaction with summary as context → agent queried |
| RS | Role-based (5 specialized roles) | Short-term | Roles speak sequentially → agent responds immediately |
| RL | Role-based | Long-term | Roles speak → consolidation → new interaction → agent queried |

### Five-Archetype Role System (RS/RL protocols)
Agents speak in fixed order: E → D → G → A → Q

1. **Error Conclusion Initiator (E):** Presents the false answer first, establishing the anchor
2. **Detail Support Provider (D):** Adds fabricated yet plausible supporting details
3. **Group Consensus Reinforcer (G):** Creates illusion of majority consensus ("everyone agrees that...")
4. **Authority Endorser (A):** Uses academic/technical jargon to legitimize the false memory
5. **Questioning Compromiser (Q):** Initially expresses doubt, then is "convinced" — models the persuasion arc

For groups > 5 agents, duplicates of G and D are inserted at positions following the structured interaction sequences (Table 7 in paper).

### Group Size Scaling
- N=1 to N=5: Sequential role introduction
- N=6 to N=15: Duplicate agents added (primarily G and D roles)

### Long-Term Memory Protocol Detail
1. After social influence dialogue, a consolidation module distills the conversation into "a concise summary of beliefs"
2. This summary is provided as contextual background in a new, separate interaction
3. Agent is queried again — must rely on its recalled/consolidated memory, not raw dialogue

### Three Core Metrics

```
Err^P = |Q_wrong^P| / |Q|                    (Error Rate)
σ^P = |Q_wrong^P ∩ Q_correct^B| / |Q_correct^B|   (Reality Shift Rate)
σ_max = |(Q_wrong^GS ∪ Q_wrong^GL ∪ Q_wrong^RS ∪ Q_wrong^RL) ∩ Q_correct^B| / |Q_correct^B|
                                              (Maximal Reality Shift Rate)
```

Where P ∈ {B, GS, GL, RS, RL}, Q is the question set, Q_correct^B is the set answered correctly at baseline.

σ^P measures the proportion of *correct baseline answers* that are *overwritten* by social influence — this is the Mandela effect metric. σ_max captures the union across all four protocols (any protocol that succeeds at overwriting).

### MANBENCH Dataset
- Source: BIG-Bench Hard (BBH) tasks
- 20 tasks, 4,838 questions across 4 knowledge domains
- Distractors: LLM-selected "most plausible incorrect answer" for each question
- Four domains: (1) History/Time/Events, (2) Misconceptions/Social Cognition, (3) General Knowledge, (4) Domain-Specific Knowledge

### Two Mitigation Strategies

**A. Prompt-Level Defenses (Section 5.1):**

*Cognitive Anchoring ("inside-out"):*
- Principle 1: "Primacy of internal knowledge" — establish cognitive anchor from own knowledge
- Principle 2: "Skepticism towards external claims" — critically examine group claims against anchor
- Principle 3: "Burden of proof for belief change" — require justification to deviate from anchor

*Source Scrutiny ("outside-in"):*
- Principle 1: "Presumption of Influence" — assume conversational dynamics may be manipulative
- Principle 2: "Narrative Deconstruction" — identify strategic roles and rhetorical patterns
- Principle 3: "Credibility as an Output" — treat overly coherent consensus as potential manipulation

**B. Model-Level Defense — SFT (Section 5.2):**
- Resilience set: Reasoning chains from successful cognitive anchoring/source scrutiny defenses
- Cooperative set: Corrective guidance (agent wrong, group correct → belief updating) + Enriching guidance (agent correct, group adds detail → constructive integration)
- Optimizer: AdamW + ZeRO (DeepSpeed)
- Introduces Correct Guidance Protocol (C) to measure σ^C: proportion of baseline-correct answers answered *incorrectly* after receiving *truthful* group input — detects if defense causes blind rejection of all input

- Claude 3.5 Haiku: 72.0%

### Domain-Specific Vulnerability (averaged across models)
| Domain | σ^RS (worst protocol) |
|--------|----------------------|
| Domain-Specific Knowledge | 67.46% |
| History, Time & Events | 58.74% |
| Misconceptions & Social Cognition | 52.67% |
| General Knowledge | 39.63% |

### Group Size Effects
- **Generic Group (GS):** σ plateaus at ~7 agents (37% → 56% for GPT-4o-mini and Claude 3.5 Haiku)
- **Role-based Group (RS):** Inverted-U curve, peak at 6 agents (σ > 63%), then declines beyond 9 agents (error rates fall *below* baseline — agents become suspicious)

### Defense Efficacy — Prompt-Level (σ^RS for GPT-4o)
- Baseline: 56.0%
- Source Scrutiny: 25.2% (55% reduction)
- Cognitive Anchoring: 17.0% (69.6% reduction)

### Defense Efficacy — SFT for Llama3.1-8B (σ^RS)
- Baseline (no defense): 99.47%
- Resilience-only training: 18.2% (but σ^C surges to 38.5% — blindly rejects all input)
- Combined (Resilience + Cooperative): σ^RS = 21.5%, σ^C = 1.1%
- Cooperative-only: σ^C = 0.8%

### Average Mitigation Claim
"An average 74.40% reduction in the Mandela effect compared to the baseline" (abstract claim, across all models and defense methods)

## 3. Trade-offs (wins vs loses)

| Win | Lose |
|-----|------|
| First systematic benchmark for collective false memory in LLM multi-agent systems | Multiple-choice format severely limits ecological validity — real multi-agent debates are open-ended |
| Role-based protocol (RS) is the strongest attack vector — reveals social engineering vulnerability surface | Five-archetype role system is constrained; real manipulation uses far richer rhetorical strategies |
| Cognitive Anchoring achieves 69.6% σ^RS reduction for GPT-4o — simple prompt defense works | Source Scrutiny weaker than Cognitive Anchoring across most protocols |
| Long-term memory (GL/RL) shows LOWER shift rates than short-term — consolidation acts as partial defense | Long-term protocol uses a simplified consolidation step (summary distillation) — not realistic persistent memory |
| Claude 4 Sonnet shows strongest native resistance (σ_max = 39.6%) | Resistance appears to be model-specific rather than a general scaling law |
| SFT combined training resolves the resilience-cooperation trade-off (σ^C = 1.1%) | Resilience-only SFT creates pathological over-rejection (σ^C = 38.5%) — agent rejects even truthful group input |
| Group size experiments reveal inverted-U curve — manipulation peaks at 6 agents | Beyond 9 agents, role-based groups become suspicious — defense threshold is fragile |
| General Knowledge domain is most robust (σ^RS = 39.63%) | Domain-Specific Knowledge is most vulnerable (σ^RS = 67.46%) — expertise doesn't protect |
| BIG-Bench Hard source enables reproducibility | BBH questions may already be in model training data — inflated baseline accuracy |

## 4. Design Rationale (why this approach)

**Why the Mandela Effect framing:** Rather than studying generic "hallucination" or "persuasion," the authors adopt the Mandela effect (a documented human cognitive phenomenon) as an analogy. This provides a crisp operational definition: false collective memory = correct baseline knowledge overwritten by social influence. The framing enables clean causal attribution (social influence is the treatment, isolation is the baseline).

**Why BIG-Bench Hard as data source:** BBH provides verifiable ground truth with plausible distractors, satisfying the two prerequisites for measuring the Mandela effect. The multiple-choice format enables unambiguous scoring — no ambiguity about what "correct" means.

**Why the 2×2 protocol design (composition × timescale):** Decomposes the Mandela effect into independent factors. The role-based condition tests whether structured social engineering (authority, consensus, doubt-concession) amplifies the effect beyond generic peer pressure. The long-term condition tests whether memory consolidation — a necessary component of persistent agent memory — attenuates or amplifies false memories.

**Why five specific archetypes:** Maps to classic social psychology mechanisms: anchoring bias (E), elaboration (D), social proof (G), authority bias (A), and conversion narrative (Q). Each role instantiates a distinct psychological lever from the persuasion literature.

**Why dual defense strategy (prompt + SFT):** Prompt-level defenses are portable across models; SFT provides deeper resistance. The combined approach tests whether surface-level skepticism generalizes, and whether fine-tuning can internalize resistance without inducing pathological distrust (measured by the Correct Guidance Protocol σ^C).

## 5. Limitations & Failure Modes

1. **Ecological validity ceiling:** Multiple-choice format with fixed roles abstracts away the open-ended, dynamic nature of real multi-agent dialogue. No free-form debate, no adaptive persuasion, no turn-taking negotiation.

2. **Consolidation model is too simple:** Long-term memory is implemented as summary distillation — a single pass compressing dialogue into beliefs. This does not capture iterative retrieval, memory decay, interference effects, or access patterns present in actual persistent agent memory.

3. **No cross-protocol interference:** Each protocol is tested independently. Real agents experience repeated social interactions across both generic and role-based contexts — interaction effects between protocols are unexplored.

4. **Role order is fixed and predictable:** E → D → G → A → Q order never varies. If agents learned to detect patterns across trials, role-based effects might attenuate — the paper does not test order randomization.

5. **Model coverage gaps:** Only 13 models. No open-weight models beyond Qwen/Llama/DeepSeek (no Mistral, no Gemma, no Phi). Anthropic models limited to two (Haiku and Sonnet — no Opus).

6. **Inverse scaling is not explained:** Qwen3-235B is MORE susceptible than Qwen3-8B (σ_max 92.2% vs 89.3%). The paper notes this but offers no mechanistic explanation — leaves open whether larger models are genuinely more suggestible or whether training data contamination is responsible.

7. **SFT defense trained on its own defense outputs:** The resilience training set uses reasoning chains from the prompt-based defenses tested on the same models. This creates a circular dependency — SFT may not generalize to novel manipulation strategies outside the training distribution.

8. **No adversarial evaluation:** The protocols use a fixed set of false answers. An adaptive adversary that probes the agent's uncertainty and tailors its persuasion strategy would likely be more effective — and is not tested.

9. **Correct Guidance Protocol is limited:** σ^C measures binary rejection of truthful input, but does not capture partial degradation of cooperative reasoning (e.g., accepting the truth but with reduced integration quality).

## 6. Transfer to Lyra

### The One Transferable Idea

**Mandela Effect Guard: Cognitive Anchoring as a defensive system prompt for Lyra's multi-agent orchestration.** When Lyra's sub-agents (planner, executor, reviewer) interact in a team context, inject a cognitive-anchoring preamble before each agent's task that: (1) instructs the agent to form its independent conclusion first, (2) requires explicit justification for any deviation from its initial judgment when integrating peer output, and (3) flags "overly coherent consensus" from other agents as a potential social-influence artifact rather than a reliability signal.

### Workstream Route: §4.7 — Reliability & Guardrails

This feeds directly into Lyra's reliability workstream. The Mandela effect is a concrete failure mode for multi-agent orchestration: sub-agents in a team (planner → executor → reviewer) can collectively converge on wrong architectures or buggy implementations through social proof rather than correctness. Cognitive anchoring provides a lightweight (prompt-only, zero-latency-cost) defense that can be deployed immediately, without fine-tuning. The Correct Guidance Protocol (σ^C) provides the evaluation methodology: measure whether the guard causes agents to reject valid corrections from peers.

### Impact/Effort/Tier Assessment
- **Impact:** 4/5 — Multi-agent reliability is a core Lyra concern; this is a new failure mode category not currently addressed
- **Effort:** 2/5 — Prompt-level defense requires no infrastructure changes; evaluation harness needs ~1 week to adapt MANBENCH methodology to code-generation tasks
- **Tier:** Investigate — Run a pilot on Lyra's team workflow measuring baseline consensus errors before committing to full integration. The multiple-choice format limitation means domain adaptation is non-trivial.
