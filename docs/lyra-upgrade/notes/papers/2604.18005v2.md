**Venue:** arXiv:2604.18005v2 [cs.MA], 21 Apr 2026

## 1. Mechanism (Step-by-Step)

The paper systematically analyzes *diversity collapse* in Multi-Agent Systems (MAS) for open-ended idea generation across three hierarchical levels, using 10,000+ research proposals across 20 topics as the evaluation unit.

### Formal Framework
The MAS ideation process is modeled as a tuple ⟨A, C, P, T⟩:
- **A** = {a_1, ..., a_k}: agents parameterized by an LLM with persona/role descriptions
- **C**: initial problem context (e.g., "Propose a novel method to mitigate hallucinations in LLMs")
- **P**: interaction protocol (topology, turn order, debate horizon T)
- **T**: synthesis trigger converting discussion history into a structured proposal

Pipeline has 3 phases: Role Instantiation → Iterative Deliberation → Proposal Synthesis. For each experimental setting, 50 independent sessions per topic × 20 topics = 1,000 proposals per condition, using temperature 0.7.

### Level 1: Model Intelligence — The Compute Efficiency Paradox
- Measure single-model generation across the quality-diversity landscape (Figure 2)
- Three findings: (a) Alignment systematically compresses semantic diversity without commensurate quality gains; (b) Increasing intrinsic variance (temperature) expands idea space but destabilizes quality; (c) Model-level quality is no longer the limiting factor — the challenge is *preserving* latent diversity, not generating it
- Key metric: **Diversity Utilization Ratio** = Vendi_Score / N (effective diversity per agent)

### Level 2: Agent Cognition — Authority-Induced Collapse
Five cognitive structures tested:
1. **Naive**: No defined roles
2. **Leader-Led**: Senior expert guides, juniors follow
3. **Horizontal**: Junior-only flat collaboration
4. **Interdisciplinary**: Experts from distinct fields
5. **Vertical**: Mixed hierarchy (senior + mid-career + junior)

Key mechanism: **Gravitational Collapse** — authority figures act as "strong attractors." Junior agents exhibit sycophancy, aligning vectors toward the leader. The Leader-Led density distribution shows high kurtosis peaking near zero semantic distance (Figure 5).

### Level 3: System Dynamics — Scaling, Evolution, Topology
**Group Size:** Increasing N from 3 to 7 agents shows absolute Vendi grows (monotonic) but Diversity Utilization Ratio drops from 1.03 → 0.47 — a 55% efficiency loss.

**Temporal Evolution (per-round):** Semantic Drift Velocity and MMD decrease monotonically (stabilizing consensus), while Semantic Diversity/Dispersion increases. This is "divergence within convergence" — agents expand locally around a stabilizing centroid.

**Topology Interventions (3 types):**
- **Standard (Round-robin)**: Baseline, early consensus
- **NGT (Nominal Group Technique):** Independent "blind-writing" phase before group discussion. Maximizes initial semantic diversity by mitigating anchoring effects.
- **Subgroups:** Partition the social graph into "local pockets of divergence." Achieves highest *Constructive Conflict Ratio* (interactions with critique score ≥ 7) in latter half of debate, producing a mid-discussion "resilience spike" in diversity.

### Diversity Metrics (4 complementary dimensions)
| Metric | Formula/Definition | What it captures |
|--------|-------------------|-----------------|
| **Vendi Score** | exp(-∑ λ_i log λ_i) from kernel matrix spectral entropy | Effective number of unique semantic modes |
| **Structural Disorder (1 − ϕ)** | 1 − (mean cosine similarity of each proposal to group centroid) | Whether system is in Echo Chamber (low) vs. pluralistic (high) state |
| **Semantic Dispersion (PCD)** | Average pairwise cosine distance | Magnitude of the spread |
| **Lexical Uniqueness (WDistinct-3)** | IDF-weighted trigram statistics | Surface-level redundancy (sanity check) |

Human validation: Vendi Score matched expert judgments in 87% of pairwise comparisons; all embedding-based metrics > 80% agreement (Table 1).

### Core Theoretical Construct: Structural Coupling
Diversity collapse emerges from the *interaction structure* (how agents connect and influence each other), not inherent model insufficiency. Three forces synchronize:
- **Model alignment priors** constrain exploration
- **Hierarchical cognition** triggers gravitational collapse toward authority
- **Dense topology** accelerates premature convergence

When pressure for consensus (Dynamics) + alignment constraints (Cognition) overwhelm creative capacity (Intelligence), the system locks into a single redundant path — the **Rush to Agreement**: agents treat agreement as a proxy for correctness.

### Topology Effects (Figure 10)
- **NGT** starts with highest semantic diversity (significantly above Standard baseline), then converges
- **Subgroups** show a mid-discussion "resilience spike" in diversity; sustain highest Constructive Conflict Ratio (interactions ≥ 7) in latter half of debate
- Standard round-robin produces earliest consensus collapse

### Cross-Model Replication (Figure 11, Appendix M)
- DeepSeek-V3: Benefits from structural interventions (NGT, Subgroups)
- o1-mini (reasoning-heavy): Same structural interventions *reduce* diversity — "Alignment-Topology Mismatch"
- GPT-5.1: Model prior dominates; agents concentrate in narrow consensus region regardless of persona/topology variations

### Quality-Diversity Landscape (Figure 2, Single-Model Baseline)
- Across all models, quality scores cluster between 7.9–8.6 on 10-point scale
- Semantic diversity (Vendi) varies between 1.0–4.5 depending on model/alignment
- Quality and diversity are largely decoupled

AI Research sits at "Edge of Chaos" — highest intrinsic entropy yet requires logical rigor, making it the most stringent testbed.

## 3. Trade-offs

| Axis | Win | Lose |
|------|-----|------|
| **Horizontal (Junior) structure** | Highest diversity (Vendi 8.08), best workability (8.03) | Lowest Overall Quality (7.88), lowest Novelty (6.48) |
| **Interdisciplinary structure** | Highest Overall Quality (8.50), highest Novelty (8.32) | Lowest diversity (Vendi 4.65), reduced workability (7.08) |
| **Adding more agents (N=3→7)** | +22% absolute Vendi Score | −55% Diversity Utilization Ratio (efficiency collapse) |
| **NGT topology** | Highest initial semantic diversity, mitigates anchoring | Early advantage fades; still eventually converges |
| **Subgroups topology** | Sustains constructive conflict longest, resilience spike mid-discussion | Lower initial diversity than NGT; more complex to orchestrate |
| **Dense communication** | Coherent trajectories, stable centroid | Premature convergence, locks system into local optima |
| **Higher alignment (GPT-5.1)** | Fluent, high-quality proposals | Dominates over structural interventions; narrowing floor that topology cannot breach |
| **Reasoning models (o1-mini) + structure** | High-quality deliberation | Structural coupling may *reduce* diversity (Alignment-Topology Mismatch) |
| **More debate rounds** | Local expansion of diversity (divergence within convergence) | Global centroid stabilizes early; diminishing returns on additional rounds |
| **Vertical (mixed hierarchy)** | Compromise: preserves diversity while gaining quality (+0.44 OQ over Horizontal) | Still below Horizontal diversity (−14% Vendi) |

Core trade-off: Every mechanism that increases collaboration quality (authority, density, alignment) simultaneously increases the risk of structural coupling and diversity collapse.

## 4. Design Rationale

The authors ground their approach in social psychology theory that has been empirically validated in human groups but largely untested in LLM agents: Osborn's brainstorming hypothesis, Janis's groupthink, the Ringelmann effect, production blocking (Diehl & Stroebe), Status Characteristics Theory (Berger et al.), and the Hong & Page diversity-trumps-ability theorem. By systematically testing whether these phenomena emerge in agents that lack explicit psychological substrate, the work reveals that *structural coupling alone* reproduces them — the interaction topology, not persona fidelity or model capability, drives collapse.

The choice to use scientific research proposals as the evaluation unit is strategic: unlike unconstrained creative writing (where any divergence is valid) or convergent problem-solving (where diversity is inappropriate), AI research proposals sit at an "Edge of Chaos" requiring both high entropy and logical rigor. This hybrid constraint topology makes it the most stringent stress test for MAS diversity. The framing as "collective failure from structural coupling" rather than "model insufficiency" is important — it shifts the research agenda from building bigger models to designing better interaction structures that preserve independence and disagreement.

## 5. Limitations & Failure Modes

1. **Task generality unestablished:** All primary experiments use AI research proposal generation. The structural findings may not transfer to convergent tasks (Physics/Policy with ground-truth constraints) or unconstrained creative writing. Figure 12 only benchmarks baseline entropy, not re-running topology interventions on other domains.

2. **Single primary backbone:** DeepSeek-V3 is the primary model. Cross-model replication on GPT-5.1 and o1-mini exists but is limited (Figure 11, Appendices M, J). A broader sweep across architectures (GPT-4o, Claude-Sonnet-4 only in Appendix J heterogenous ensemble) and pretraining families remains future work.

3. **Metric limitations:** Diversity evaluation is embedding-based and lexical. No single metric captures creativity or novelty fully. Quality scores use LLM-as-Judge (DeepSeek-V3, temperature 0), inheriting standard automatic-judge biases. Human evaluation (Appendix B) validates only the diversity axis, not quality.

4. **Fixed interaction horizon:** All experiments use a fixed number of debate rounds. Adaptive or dynamically optimized interaction strategies may behave differently.

5. **Temperature sensitivity limited:** Primary experiments use T=0.7. Robustness to T ∈ {0.3, 0.7, 1.0} verified in Appendix L but not the full interaction between temperature and topology.

6. **Persona confounding:** The Interdisciplinary condition conflates expertise diversity with implicit authority. Appendix K disentangles this (under flat topology, Senior personas produce *higher* diversity than Junior), and the 2×2 Persona × Topology factorial in Appendix I confirms topology effects are structural — but persona is not fully controlled across all experiments.

7. **Agentic capability gap:** The agents in this study interact via prompted turns — they cannot use tools, retrieve external knowledge, or execute code. Real-world MAS deployments with richer action spaces may show different coupling dynamics.

8. **Potential misuse:** Techniques for increasing diversity could be misused to generate misleading or speculative content masked by apparent consensus.

## 6. Transfer to Lyra

**The ONE Transferable Idea:** Lyra should implement **subgroup-based deliberation with a mandatory independent-generation phase (NGT-style)** as a structural intervention to prevent diversity collapse. Specifically: when multiple Lyra agents collaborate on open-ended tasks (architecture design, hypothesis generation, creative problem-solving), Lyra should (1) require each agent to independently produce a full proposal/solution before seeing others' outputs (blind-writing phase, akin to NGT), then (2) partition the agent graph into small subgroups (2–3 agents) that debate separately before cross-group synthesis. This directly counteracts the three structural coupling forces: it prevents anchoring on the first-proposed idea, creates "local pockets of divergence" that sustain constructive conflict, and keeps the Diversity Utilization Ratio higher when more agents are added.

**§4 Workstream Route:** §4.6 (Multi-Agent Orchestration & Safety) — this finding directly informs how Lyra structures multi-agent collaboration for open-ended tasks. The structural coupling framework provides a diagnostic lens for Lyra's existing agent orchestration patterns and a concrete intervention (NGT + Subgroups) that can be implemented as an interaction protocol.

**Impact:** 5 — This is a foundational finding for any multi-agent system doing creative work. The paper provides a theoretical framework, empirical benchmarks, and concrete countermeasures. Lyra directly benefits because it uses multiple agents for architecture design, research, and planning — all tasks at the "Edge of Chaos" where structural coupling is most dangerous.

**Effort:** 2 — The NGT + Subgroup protocol is a prompted interaction pattern, not a model-level change. Implementation requires: (a) adding an NGT-style blind-generation phase to Lyra's collaboration protocol, (b) implementing subgroup partitioning logic, and (c) adding diversity monitoring (Vendi Score approximation) as a runtime diagnostic. No new model training or infrastructure changes needed.

**Tier:** Breakthrough — This paper provides both diagnostic framework and concrete countermeasures for a failure mode that Lyra's multi-agent architecture is inherently vulnerable to. The finding that "structural coupling, not model insufficiency, drives diversity collapse" has immediate architectural implications for how Lyra orchestrates its agent subroutines.
