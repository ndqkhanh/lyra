## 1. Mechanism (step-by-step)

Dialectic-Med operationalizes Popperian falsification through a three-agent adversarial dialectic loop with explicit visual evidence grounding. The core innovation is the **Visual Falsification Module (VFM)**, which forces the Opponent agent to ground its counter-arguments in pixel-level image evidence rather than generating plausible-sounding but fabricated rebuttals.

### Agent Roles

| Agent | Role | Function |
|-------|------|----------|
| **Proponent** (A_P) | Primary diagnostician | Analyzes image I + query Q, generates initial hypothesis h_0, revises upon counter-evidence |
| **Opponent** (A_O) | Scientific skeptic | Generates counterfactual probes, uses VFM to localize contradictory visual evidence |
| **Mediator** (A_M) | Impartial adjudicator | Evaluates debate quality, manages Dynamic Consensus Graph, terminates loop, generates final explanation |

### Step 1: Hypothesis Generation
At t=0, the Proponent analyzes image I and query Q to propose initial hypothesis h_0. Graph initialized: V_0 = {h_0}, E_0 = ∅.

### Step 2: Counterfactual Probe Generation
The Opponent generates a targeted counterfactual query Q_cf:
```
Q_cf = GenProbe(H_t, K_med)
```
where K_med encodes domain knowledge. For hypothesis "Pneumonia", the probe becomes "Identify features contradicting pneumonia, specifically signs of volume loss."

### Step 3: Visual Falsification (VFM)
The VFM uses PubMedCLIP (ViT-B/16 backbone) to ground Q_cf in image I:

**Falsification Attention Map computation:**
- Image patch embeddings: V = {v_1, ..., v_N}
- Probe text embedding: q = E_txt(Q_cf)
- Relevance score for patch i:
  ```
  s_i = (q^T v_i) / (||q|| ||v_i|| √d)
  ```
- Softmax-normalized attention with temperature τ:
  ```
  α_i = exp(s_i/τ) / Σ_j exp(s_j/τ)
  ```
- High α_i values highlight regions contradicting the hypothesis (evidence of absence)

**Attack Strength** quantifies visual grounding confidence:
```
S_attack(e_t) = (1/|R_k|) Σ_{r∈R_k} α_r
```
where R_k = top-k patches with highest attention weights.

**Critical gate:** If S_attack < θ_thresh (default 0.3), the attack is deemed weak → loop terminates (consensus reached).

### Step 4: Graph Expansion
When attack is valid:
- Add counter-evidence node e_t and revised hypothesis node h_t
- Falsification edge: (h_{t-1}, e_t) weighted by w = S_attack
- Rectification edge: (e_t, h_t) weighted by w = Proponent's output confidence ∈ [0,1]
- Cycle detection: if sim(h_t, h_j) > θ_sim (0.8) for any prior hypothesis h_j, prune branch

### Step 5: Mediated Revision
```
f_b_t = Mediator(h_{t-1}, e_t)          # Evaluate counter-evidence validity
h_t = Proponent(h_{t-1}, e_t, f_b_t)    # Revise hypothesis with feedback
```

### Step 6: Consensus Aggregation (Path Integration)
The **Cumulative Credibility Score** for leaf hypothesis h integrates over all reasoning paths:
```
Φ(h) = Σ_{π∈Π(h_0→h)} exp( (1/|π|) Σ_{(u,v)∈π} log(w_uv) )
```
Final diagnosis: D* = arg max_{h∈V_leaf} Φ(h)

This path-integration approach ensures the winning diagnosis is the one that best survived the chain of visual falsification and rectification, mitigating the "lost-in-the-middle" effect.

### Training Objective: Counterfactual Grounding Loss (L_CFG)
Uses triplets (I, Q^+, Q^-) where Q^+ matches ground truth and Q^- is counterfactual:
```
L_CFG = -log[ exp(S(Q^+,M^+)/τ) / Σ_{k∈{+,-}} exp(S(Q_k,M_k)/τ) ]
```
Split into Proponent Grounding Loss (L_P) and Opponent Grounding Loss (L_O):
```
L_total = L_LM + β · (λ_P L_P + λ_O L_O)
```
Fine-tuned on ROCO dataset with bounding box annotations.

### Algorithm Complexity
O(T_max · (C_VFM + C_LLM)) where T_max ∈ [3,5]. Graph operations O(|V|²) are dominated by LLM inference cost. |V| ≤ 2T_max + 1.

## 2. Results (real benchmark numbers with units)

### Diagnostic Accuracy

| Benchmark | Dialectic-Med (best backbone) | Best Baseline | Absolute Gain |
|-----------|-------------------------------|---------------|---------------|
| **VQA-RAD** | 80.45% ±0.95 (GPT-5.1) | 76.40% ±1.56 (GPT-5.1 CoT) | **+4.05%** |
| **PathVQA** | 72.32% ±0.88 (GPT-5.1) | 68.92% ±1.42 (GPT-5.1 CoT) | **+3.40%** |
| **MIMIC-CXR-VQA** | 76.28% ±1.75 (GPT-5.1) | 68.10% ±2.15 (GPT-5.1 CoT) | **+8.18%** |

Key efficiency finding: Dialectic-Med with **Qwen3-VL-8B backbone achieves 70.35%** on VQA-RAD, beating the much larger Qwen3-VL-32B with standard CoT (68.96%) and crushing domain-specific LLaVA-Med (56.20%).

|--------|-----------|--------|---------------|-------------------|
| **CHAIR_S** (sentence-level) | 18.4% | 14.2% | **10.7%** | **-41.8%** vs GPT-4o |

Expert evaluation: 3 board-certified radiologists, double-blind, 1-5 faithfulness rubric.

### Ablation: Component Attribution (MIMIC-CXR-VQA)

| Ablation | Accuracy | Δ from Full |
|----------|----------|-------------|
| Full Dialectic-Med | 72.46% | — |
| w/o Opponent (No Falsification) | 67.02% | **-5.44%** |

The VFM removal causes the single largest degradation (-9.31%), empirically proving that text-only debate is "fundamentally inadequate" for high-stakes domains.

### Architecture Fairness (Mixed Model Pool)

With heterogeneous backbones (LLaVA-Med-1.5, Qwen3-VL-32B, GPT-4o):
- Dialectic-Med: 71.82% (MIMIC-CXR-VQA), 77.37% (VQA-RAD)
- ReConcile (Mixed): 64.12%, 72.85%
- MedVCD (Mixed): 67.50%, 74.10%

### Hyperparameter Sensitivity
- **θ_attack**: Stable at 0.2-0.4 (71.85-72.46%). At 0.6, degenerates to CoT (66.10%). At 0.1, overly aggressive false rejection (68.40%).
- **θ_sim**: 0.8 is Pareto-optimal. Saves ~15% computational turns (2.6 avg vs 3.0 maxed at θ_sim=0.9).

### Cost-Performance Profile
- Token consumption: 3.8-4.5k per query (vs 0.8-1.2k for single-pass CoT)
- Cost: ~$15-23 per 1000 queries (vs $34-60 for unconstrained agentic frameworks)
- 60-70% cheaper than MedAgent/ReConcile while outperforming them

## 4. Design Rationale (why this approach)

1. **Popperian epistemology over verificationism:** Standard CoT is a "verificationist trap" — it seeks evidence that confirms each step, propagating errors. Popperian falsification demands that hypotheses survive rigorous refutation attempts. This philosophical grounding is the paper's central intellectual move.

2. **Explicit visual grounding over implicit attention:** Prior multi-agent debate approaches use text-only argumentation. The authors demonstrate that in vision-dependent domains, text-only opponents hallucinate plausible-sounding but physically non-existent rebuttals. The VFM forces grounding in actual pixel regions, confirmed by the catastrophic -9.31% drop when VFM is removed.

3. **Structured graph memory over linear context:** The Dynamic Consensus Graph prevents the "lost-in-the-middle" phenomenon common in long-context debate. By weighting edges by visual confidence and computing cumulative credibility over paths, early high-confidence counter-evidence is preserved through aggregation.

4. **3-agent dialectic over N-agent consensus:** Rather than majority voting or static consensus, the Proponent-Opponent-Mediator triad creates a structured adversarial relationship. The Mediator's role as impartial adjudicator (not participant) prevents the debate from becoming pure semantic argument.

5. **Counterfactual probe generation over simple negation:** The Opponent doesn't just say "you're wrong" — it generates targeted queries for specific contradictory features, operationalizing the clinical differential diagnosis process.

## 5. Limitations and Failure Modes

1. **Synchronous latency barrier:** The multi-turn loop incurs fundamental latency overhead. Unsuitable for emergency triage with sub-minute response requirements. Suitable only for asynchronous workflows (retrospective report generation, second-opinion review).

2. **VFM visual acuity ceiling:** The VFM is bounded by PubMedCLIP ViT-B/16 pre-training distribution. Fails for:
   - Sub-3mm micro-pathologies (below patch resolution)
   - Severe OOD rare conditions underrepresented in ROCO fine-tuning data
   - When the Opponent cannot retrieve localized counter-evidence → false consensus (incorrect diagnosis affirmed)

3. **Heuristic threshold fragility:** θ_attack (0.3) and θ_sim (0.8) are validated on a specific validation set. Deploying across divergent medical sub-specialties (e.g., dermatology vs radiology vs pathology) may require sub-specialty-specific calibration.

4. **Mediator residual bias:** The Mediator is still a parametric LLM. It may exhibit ingrained confirmation biases from pre-training — rejecting logically sound counter-evidence or favoring hypotheses that align with its training distribution priors.

5. **No real-time clinical validation:** All evaluations are on retrospective benchmark datasets. No prospective clinical deployment study. The expert evaluation (3 radiologists, 1-5 scale) provides signal but lacks the statistical power of a full clinical trial.

6. **Model lock-in:** The VFM is tightly coupled to PubMedCLIP ViT-B/16. Performance characteristics may not transfer to other vision backbones without retraining the CFG loss objective.

7. **Bias inheritance:** The underlying foundation models may harbor demographic biases. Falsification sensitivity might vary across patient populations — fairness auditing is listed as future work, not completed.

## 6. Transfer to Lyra

### The One Transferable Idea

**Adversarial Falsification Verification (AFV):** Replace or augment the existing SABER mutation-testing verification strategy with an active falsification loop. Instead of checking "does this output contain bugs?" (verification), ask "what would prove this output is WRONG?" (falsification). A dedicated Opponent agent, equipped with a code-aware grounding module (analogous to VFM but operating on code structure/execution traces rather than image patches), actively seeks evidence that contradicts the agent's output claim. A Mediator adjudicates whether the falsification evidence is valid, and the final output is selected via a confidence-weighted consensus graph.

### Workstream Route: §4.16 (Reliability & Observability)

This paper directly informs Breakthrough Idea 2 in brainstorm/16-reliability.md ("Cross-Agent Consensus Verification with Collusion Detection"). The VFM pattern provides the missing "grounding" mechanism — ensuring the Opponent's counter-evidence is anchored in actual data (code execution results, type checker output, test failures) rather than hallucinated rebuttals. The Dynamic Consensus Graph provides the structured memory architecture needed to prevent the "lost-in-the-middle" problem in multi-turn verification debates.
