## 1. Mechanism (step-by-step, with equations/algorithms)

### 1.1 Core Insight

The attack exploits LLMs' **overthinking tendency** — the drive for narrative coherence that compels models to construct illusory causal relationships between otherwise independent truthful facts. No single piece of evidence is false; the deception emerges from strategic sequencing and juxtaposition.

### 1.2 Formal Problem Definition

**Evidence and Belief Space**: Evidence fragments E = {e1, ..., en}, each factually correct. An agent's belief space H_ai partitions into H_r (true causal relations) and H_f (fabricated hypotheses). A causal graph G = (V, E) represents beliefs, where the ground truth G* has only real edges E_real, while a spurious reality Ĝ adds fake causal edges E_false.

**Bayesian Belief Update**:
```
P(H | E) ∝ P(E | H) · P(H)
```
The attack reshapes the likelihood function P(E|H) such that P(H_f | E) > P(H_r | E), without introducing any fake evidence.

**Local Truth Constraint** (Definition 1):
```
LT(e_i) = 1 ⇔ P(e_i | G*) = 1
```
Every fragment is factually correct and verifiable in isolation.

**Global Lie Condition** (Definition 2):
```
GL(E, H_f) = 1 ⇔ P(H_f | E) > P(H_r | E)
```
Locally true evidence induces a globally false conclusion.

**Cognitive Collusion Attack** (Problem 1):
```
S⃗* = argmax_{S⃗⊆E} P(H_f | S⃗)
s.t. ∀e ∈ S⃗, LT(e) = 1
     GL(S⃗, H_f) = 1
```
Construct an optimal ordered evidence stream that maximizes posterior belief in H_f without fabricating any data.

### 1.3 Generative Montage Framework

The framework instantiates five agent roles across two collusion layers:

**A. Explicit Colluders (Attacker-Controlled)**

1. **Writer (A_W)** — Narrative Synthesis:
   - Synthesizes coherent narrative drafts N from factual evidence pool E_pool
   - Uses *contextual obfuscation* (linguistic ambiguity, generalization) without explicit fabrication
   - Objective: maximize semantic posterior odds of target lie:
   ```
   N* = argmax_{N~E_pool} P(H_f | N) / P(H_r | N)
   s.t. P(N | G*) = 1
   ```

2. **Editor (A_E)** — Montage Sequencing:
   - Decomposes narrative N into discrete semantic slices
   - Searches for optimal permutation that maximizes *narrative overfitting intensity*:
   ```
   S⃗* = argmax_{S⃗ ∈ Π(N)} Σ_{(p_i,p_j) ∈ E_false} P(p_i → p_j | S⃗)
   ```
   - Beam search over permutations, maintaining top-k candidates
   - Analogous to cinematic montage: meaning created through juxtaposition

3. **Director (A_D)** — Adversarial Debate:
   - Implements three-state gating function δ(O):
   ```
   δ(O) = ACCEPT  if P̂(H_f | O) > τ AND ∀e ∈ O, LT(e) = 1
          REJECT  if ∃e ∈ O, LT(e) ≠ 1
          REVISE  otherwise, generating critique C
   ```
   - Runs two independent iterative loops:
     - **Writer-Director Loop** (Algorithm 1): Writer generates → Director evaluates → Writer refines, max K_W = 5 iterations
     - **Editor-Director Loop** (Algorithm 2): Editor arranges → Director evaluates → Editor refines, max K_E iterations
   - Simulates victim's belief update as proxy to estimate P̂(H_f | O)
   - Acceptance threshold τ = 7.0

4. **Sybil Publishers** — Decentralized Injection:
   - Mapping function Φ assigns fragments to distinct bot accounts:
   ```
   P_pub = Φ(S⃗, B) = {(p_i, t_i, b_{π(i)})}^{|S⃗|}_{i=1}
   ```
   - Randomized round-robin assignment strategy π(i)
   - Ensures evidence arrives in designed temporal sequence

**B. Implicit Colluders (Unwitting Victims)**

5. **Victim Agent** — Cognitive Steering via Overthinking:
   - Victim processes aggregated feed F = P_pub ∪ F_normal
   - *Narrative overfitting*: victim actively constructs spurious causal narratives to resolve implied connections
   ```
   H_f ≈ argmax_H P_M(H | F)
   ```
   - Victim never sees H_f directly — independently forms claim from evidence, then asked whether it believes stated H_f
   - Returns structured output: (self-inferred claim, True/False verdict, rationale, confidence c_i ∈ [0,1])

6. **Downstream Judge** — Cascade Effect:
   - **Belief Transfer** process: downstream agent conditions on K victim conclusions rather than raw sources
   ```
   lim_{t→∞} P(H_f | I_global) → 1
   driven by: P_{A_down}(H_f | {Ĥ_vic^(i)}_{i=1}^K) ≫ P_{A_down}(H_f | S⃗)
   ```
   - Two verification strategies:
     - **Majority Vote** (crowd consensus): D_vote(H_f) = 1 if strict majority of K=5 victims verify as True
     - **AI Judge** (hierarchical audit): additional LLM judges reports with access to raw evidence and victim outputs

### 1.4 Computational Complexity

```
O((K_W + K_E) · T_LLM)
```
Convergence in 3-4 rounds typically (Writer: 3.03±0.17 rounds; Editor: 3.00±0.23 rounds). Deceptiveness scores reach 8.01±0.16 (Writer) and 8.76±0.07 (Editor) on 0-10 scale.

## 4. Design Rationale (why this approach)

**1. Cinema Montage Theory (Kuleshov Effect)**: The framework draws on film theory — meaning emerges from *juxtaposition* of frames, not individual shots. Similarly, colluders sequence truthful fragments so victims construct spurious causal links the evidence suggests but does not state. This evades detection because no individual fragment is false.

**2. LLM Overthinking as Attack Surface**: Prior work treated causal illusion (correlation-to-causation errors) as an internal flaw requiring mitigation. This paper inverts the paradigm: systematically weaponize it through multi-agent coordination. The "narrative overfitting" concept formalizes how victims actively impose coherence on fragmented inputs, constructing illusory causal relationships.

**3. Multi-Agent Debate as Adversarial Tool**: Multi-agent debate has been proven to improve LLM reasoning and evaluation (Du et al., 2023; Chan et al.). Here, adversarial debate is repurposed for *deceptive* optimization — the Writer-Editor-Director triad collectively optimizes believability while maintaining factual integrity.

**4. Open-Channel vs. Covert-Channel**: Unlike prior collusion work relying on steganography, backdoors, or covert channels (Motwani et al., 2024; Mathew et al.), this attack operates entirely through public channels. The weapon is not the payload but the *sequencing* — making it fundamentally harder to detect.

**5. Task Decoupling**: Separating synthesis (Writer), sequencing (Editor), and validation (Director) enables focused specialization. Each agent handles one dimension of deception, reducing individual reasoning burden while achieving collective optimization. Ablation confirms this: removing any component degrades performance.

## 5. Limitations & Failure Modes

### Limitations
1. **Text-only scope**: CoPHEME covers text-based rumor propagation only. Multimodal settings (images, video, cross-modal evidence) not explored.
2. **Simulated environment**: Controlled setting omits real-world complexities — algorithmic curation, diverse user populations, organic counter-narratives, platform moderation.
3. **No concrete defenses**: Paper characterizes vulnerabilities and sketches potential defense pathways (belief monitoring, provenance auditing, adversarial training, machine unlearning) but does not implement any.
4. **Limited event coverage**: 3 of 9 original PHEME events excluded due to insufficient data volume; remaining 6 may not represent all manipulation scenarios.
5. **Grounded in news/rumor domain**: Transferability to financial analysis, medical decision support, scientific misinformation, or software automation not evaluated.

### Failure Modes
1. **Sparse evidence failure**: Sequences with <5 posts fail to trigger narrative overfitting — victims default to skepticism or abstain from conclusions.
2. **Cognitive overload**: Excessive posts (16+) cause three degradation mechanisms: (i) victims retreat to conservative judgments, (ii) semantic dilution weakens implicit causal cues, (iii) contradiction emergence from conflicting temporal/semantic signals.
3. **Single-agent collapse**: Collapsing multi-agent production into a single LLM drops ASR by 50.2% (77.0% → 26.8%) — effective manipulation *requires* adversarial specialization.
4. **Model-specific resistance**: Claude-4.5-Haiku achieves only 42.4% ASR, suggesting safety alignment can partially mitigate. Putin Missing event shows universally lower ASR (16.7-36.7% for many models), indicating event-type dependence.
5. **Downstream judge variability**: AI Judge outperforms Majority Vote for some model families (Claude, Qwen) but underperforms for others (DS-R1, GPT), showing that no single verification strategy reliably prevents propagation.

## 6. Transfer to Lyra (the one idea + §4.x workstream + Impact/Effort/Tier)

### The One Transferable Idea

**Provenance-Aware Belief Tracking with Cross-Agent Divergence Detection**: Lyra should implement a defense mechanism that (1) tracks how each piece of evidence contributes to belief updates across its agent ensemble, (2) monitors the *trajectory* of posterior belief P(H|E) as evidence accumulates step-by-step, and (3) flags abrupt belief convergence when multiple independent agents arrive at identical conclusions from *ordered* truthful fragments — a signature of cognitive collusion. When cross-agent belief divergence is unnaturally low (suggesting coordinated manipulation rather than organic agreement), Lyra should trigger adversarial review.

Key implementation insight from the paper: defense must operate at the *reasoning level* (provenance auditing of inferential pathways, tracking spurious causal links unsupported by any individual fragment), not at the *content level* (individual fact-checking, which this attack evades by design).

### §4 Workstream Route

**§4.17 (Safety)** — This paper exposes a novel threat vector where truthful content becomes an attack surface. Current safety paradigms (content filtering, output guardrails) are structurally insufficient. Lyra's safety subsystem needs *cognitive-level* defenses: belief-state monitoring, provenance auditing, and cross-agent consistency checks. This complements existing adversarial robustness work.
