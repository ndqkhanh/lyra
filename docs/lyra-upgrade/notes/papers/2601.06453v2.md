## 1. Mechanism (Step-by-Step)

ConSensus is a **training-free, single-round multi-agent framework** for multimodal sensing tasks. It decomposes the problem into modality-specialized agents and fuses their outputs via a hybrid mechanism.

### Algorithm

**Step 1 — Task Decomposition:** Each sensing modality (IMU, ECG, audio, accelerometer, etc.) is assigned to a dedicated LLM agent. Each agent receives:
- Few-shot labeled examples (`--examples_per_class`) for in-context learning
- Raw sensor readings from its assigned modality only
- Deterministic greedy decoding (`temperature=0.0`, `top_p=1.0`)

**Step 2 — Independent Inference:** Each modality agent produces a prediction \( y_i \) for its modality \( m_i \), with an associated confidence score or log-probability. No inter-agent communication occurs at this stage.

**Step 3 — Hybrid Fusion:**

The core contribution is the **Hybrid Fusion Mechanism** that combines two complementary strategies in a single round:

- **Semantic Aggregation (\(F_{sem}\)):** The raw text outputs and reasoning traces from all modality agents are concatenated and passed to an aggregator LLM. This aggregator performs cross-modal reasoning — it understands relationships between modalities (e.g., "high heart rate + low accelerometer activity = resting stress") and resolves contradictions by interpreting context. This captures semantic relationships that pure voting misses.

- **Statistical Consensus (\(F_{stat}\)):** Each agent's prediction is treated as a vote, weighted by confidence. The statistical consensus computes a confidence-weighted majority:

\[
y_{stat} = \arg\max_{c} \sum_{i=1}^{n} w_i \cdot \mathbb{1}[y_i = c]
\]

where \( w_i \) is the confidence weight from agent \( i \), and \( \mathbb{1} \) is the indicator function.

**Step 4 — Dual Compensation:**

The two fusion outputs (\(y_{sem}\), \(y_{stat}\)) are combined via a gating function. When the statistical consensus has high agreement (low entropy across agents), \(F_{stat}\) dominates. When agent outputs diverge (high entropy), \(F_{sem}\) is trusted more because it can reason about *why* the disagreement exists. This is formalized as:

\[
y_{final} = \begin{cases}
y_{stat} & \text{if } H(p) < \tau \\
y_{sem} & \text{if } H(p) \geq \tau
\end{cases}
\]

where \( H(p) \) is the entropy of the prediction distribution across agents and \( \tau \) is an entropy threshold.

**Step 5 — Single-Round Output:** Unlike iterative debate/RAG-based multi-agent methods (Debate, MAD, CMD, ReConcile) that require multiple rounds of agent communication, ConSensus produces the final prediction in **one round**, yielding a 12.7x reduction in fusion token cost.

### Data Flow

```
Sensor Data → [Modality Agent 1] → y₁, conf₁  ─┐
             [Modality Agent 2] → y₂, conf₂  ──┤
             [Modality Agent 3] → y₃, conf₃  ──┤
             ...                               │
             [Modality Agent n] → yₙ, confₙ  ──┘
                                                    ↓
                    ┌──────────────┬──────────────────┐
                    │  Statistical │    Semantic      │
                    │  Consensus   │   Aggregation    │
                    │  (F_stat)    │    (F_sem)       │
                    └──────┬───────┴────────┬─────────┘
                           │                │
                           └───────┬────────┘
                                   ↓
                            Gating (H(p))
                                   ↓
                               y_final
```

### Robustness to Missing Modalities

The framework supports `--missing_ratio` (e.g., 0.3 = 30% of modalities randomly dropped). When a modality is missing:
- \(F_{stat}\) simply excludes that agent's vote
- \(F_{sem}\) receives an explicit "MODALITY UNAVAILABLE" token, allowing the aggregator to reason with the remaining context

### Baselines Compared

Seven baselines are implemented and compared:
1. **Single Agent** — one LLM receives all modalities concatenated
2. **Self-Consistency** — 3 stochastic samples (temp=0.7), majority vote
3. **Self-Refine** — iterative self-critique and refinement
4. **Debate** — multi-agent iterative argumentation
5. **MAD** — Multi-Agent Debate with structured rebuttals
6. **CMD** — Consensus-based Multi-agent Discussion
7. **ReConcile** — round-table discussion with confidence-weighted reconciliation

## 3. Trade-offs

| Win | Lose |
|-----|------|
| +7.1% avg. accuracy over single agent (training-free) | Higher inference cost than single agent (N parallel LLM calls) |
| 12.7x cheaper than iterative debate methods | Semantic aggregator adds latency (sequential after agent calls) |
| Robust under up to 50% missing modalities (degrades gracefully) | Performance ceiling tied to underlying LLM capability |
| Single-round execution — practical for real-time deployments | Cannot benefit from multi-round refinement in edge cases |
| Dual-fusion compensates for each strategy's failures | Gating threshold τ requires tuning per domain |
| Works across 5 heterogeneous sensing domains | Not tested outside wearable/mobile sensing |
| Model-agnostic: works with open-source (Llama) and proprietary (GPT-4) | Deterministic greedy decoding limits diversity in agent reasoning |

## 4. Design Rationale

**Why multi-agent over monolithic:** Single LLMs exhibit *prior-knowledge bias* — they over-rely on statistical patterns in their training data rather than faithfully interpreting the specific sensor readings at hand. They also struggle to reason coherently across heterogeneous modalities with different temporal resolutions, sampling rates, and physical semantics.

**Why hybrid fusion over pure voting or pure semantic:** Pure statistical consensus (\(F_{stat}\)) is robust to individual agent noise but fails when multiple modalities provide genuinely conflicting information — it can drown out a correct minority. Pure semantic aggregation (\(F_{sem}\)) captures cross-modal relationships but is vulnerable to LLM hallucination and verbosity bias. The hybrid approach uses entropy as a principled signal for when to trust each mechanism: low-entropy agreement → statistical consensus is reliable; high-entropy disagreement → semantic reasoning is needed to resolve the conflict.

**Why single-round over iterative debate:** Iterative debate (3-5 rounds) achieves similar accuracy but at 12.7x the token cost per fusion step, making it impractical for latency-sensitive and cost-constrained deployments. The authors show that well-structured single-round fusion with dual compensation matches iterative debate performance.

**Why training-free:** Sensor deployments vary dramatically in hardware, sampling rates, and label spaces. Retraining for each deployment is infeasible. The training-free design means ConSensus works out-of-the-box on new sensor configurations with only prompt engineering.

## 5. Limitations and Failure Modes

1. **LLM Quality Ceiling:** If the base LLM cannot accurately interpret a specific modality (e.g., raw EEG waveforms), ConSensus cannot compensate — garbage in, garbage out at the agent level propagates to the fusion layer.

2. **Token Cost Multiplier:** N modality agents + 1 aggregator = N+1 LLM calls per prediction. For 6-modality tasks, this is 7x the inference cost of a single-agent approach (though still cheaper than iterative debate).

3. **Entropy Gating Failures:** When all agents agree on a *wrong* answer with high confidence (low entropy, high conviction), the gating function trusts \(F_{stat}\) and propagates the collective error. The paper shows this occurs in approximately 8-12% of failure cases.

4. **Semantic Aggregator Hallucination:** When \(F_{sem}\) is invoked under high entropy, the aggregator LLM may fabricate cross-modal relationships that do not exist in the data ("seeing patterns in noise").

5. **Domain Generalization Unproven:** All 5 benchmarks are in wearable/mobile sensing. The approach has not been tested on other multimodal domains (e.g., autonomous driving sensor fusion, medical imaging + clinical notes, audio-visual speech recognition).

6. **Threshold Sensitivity:** The entropy threshold τ for gating between \(F_{stat}\) and \(F_{sem}\) is tuned per dataset. In a truly deployment-agnostic setting, this would require automatic calibration.

7. **Latency:** While single-round, the N parallel agent calls are gated by the slowest agent response, and the semantic aggregator runs sequentially after all agents complete.

## 6. Transfer to Lyra

### The One Idea: Hybrid Semantic + Statistical Consensus for Multi-Subsystem Fusion

Lyra has multiple reasoning subsystems (memory retrieval, context assembly, planning, tool execution, reflection). Currently, these operate in a mostly sequential or ad-hoc aggregation pattern. ConSensus provides a principled fusion algorithm:

1. **Each Lyra subsystem acts as a "modality agent"** producing a judgment/action with confidence
2. **Statistical consensus** (confidence-weighted voting) provides fast, noise-robust fusion when subsystems agree
3. **Semantic aggregation** (LLM cross-reasoning) kicks in when subsystems disagree, resolving conflicts by understanding *why* they diverge
4. **Entropy-based gating** dynamically chooses which fusion strategy to trust

This is directly applicable to Lyra's §4.6 workstream (Multi-Agent Orchestration / Supervisor), where the Orchestrator must fuse outputs from Memory, Context, Tool Selection, and Planning subsystems into a single coherent action. The hybrid fusion approach would replace the current linear/sequential decision chain with a principled fusion that degrades gracefully under subsystem failures.
