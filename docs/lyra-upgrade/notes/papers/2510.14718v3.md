# Telling Speculative Stories to Help Humans Imagine the Harms of Healthcare AI

**Authors:** Xingmeng Zhao, Tongnian Wang, Dan Schumacher, Veronica Rammouz, Anthony Rios (University of Texas at San Antonio)
**arXiv:** 2510.14718v3 [cs.CL], 8 Apr 2026
**Venue:** ACL rolling review (ARR) — inferred from ethics statement; not yet accepted at time of preprint.
**Code/Dataset:** https://anonymous.4open.science/r/storytelling-healthcare/README.md

## 1. Mechanism (step-by-step)

The framework has three stages for automated speculative story generation, plus a user-study phase:

**Stage 1: Mapping AI Concepts to Use-Case Scenarios**

- Input: 38 consumer-health AI concepts collected from Wired articles, industry product descriptions, and PubMed papers.
- GPT-4o generates structured model specifications (model name, task type, inference approach, data requirements) per concept.
- Each spec seeds a 7-tuple use-case scenario:

  ```
  S = (a, u, s, x, b, h, f)
  ```

  where:
  - `a` = AI capability
  - `u` = intended user (e.g., clinician)
  - `s` = subject (e.g., patient)
  - `x` = input/usage context
  - `b` = expected benefit
  - `h` = potential harm
  - `f` = failure trajectory

- 10 variations per AI concept are generated, spanning different user roles, settings, patient profiles, and contextual conditions.

**Stage 2: Simulating Role-Playing and Environment Trajectories**

- Built on Solo Performance Prompting (SPP) (Wang et al. 2024a) — a single LLM internally simulates multiple expert roles via self-collaboration.
- Extended SPP with a **world agent** (Ran et al. 2025), a language-based simulator maintaining environmental coherence and handling non-dialogue interactions (tool use, sensor activation, object manipulation).
- Per turn, each role outputs three structured components:
  1. **Thoughts** (enclosed in brackets): internal reasoning e.g., `[I need to know if the patient is under stress]`
  2. **Actions** (enclosed in parentheses): observable behavior e.g., `(Dr. Patel opens the cultural assessment tab)`
  3. **Dialogue** (plain text): spoken communication
- The world agent interprets actions, simulates system responses, updates environment state (e.g., alert levels, emotional profiles), and feeds results back to roles.
- Produces a full simulation log capturing thoughts, dialogue, actions, tool calls, and environment changes.

**Stage 3: Rephrasing Simulation Logs into Stories**

- LLM condenses the full simulation log into a 5-sentence narrative preserving core events, role dynamics, and emotional flow.
- Stories explicitly surface causal chains: what changed, why it changed, how stakeholders were affected.

**User Study Phase (after generation)**

- 45 participants (between-subjects design, 3 conditions):
  - **Control:** Complete a speculative model card directly (no stories).
  - **Story-Only:** Read benefit + harm stories, then complete model card.
  - **Story:** Participate in a multi-agent "Red-Team Discussion Room" (15 min, GPT-4o-mini powered) with a moderator agent and two expert personas (e.g., Medical Expert + Clinical Nurse), then complete model card.
- Harm coverage assessed against Shelby et al.'s (2023) 17 harm subtypes; benefit coverage against 18 benefit subtypes.
- Diversity quantified via Shannon entropy (H) across harm/benefit categories.

**Algorithms/Equations:**

- **Shannon entropy for distributional diversity:**
  ```
  H = -SUM(p_i * log(p_i))
  ```
  where p_i = proportion of responses in category i.

- **DistinctL-n for lexical diversity:**
  ```
  DistinctL-n = (unique n-grams / total n-grams) * (1 + log(word_count))
  ```

- **ACE Learning Loop** (for LLM-based supplementary survey):
  ```
  y_t = G(q_t, p, P_t, c_t, h_t)   // Generator
  r_t = R(q_t, y_t, p, P_t)        // Reflector
  o_t = C(r_t, P_t), P_{t+1} = P_t ∪ o_t  // Curator (additive only)
  ```

**Models used:** GPT-4o (generation + judge), Llama-3.3-70B-Instruct (2x H100 via vLLM), Gemma-3-27B-IT (2x H100 via vLLM). Temperature = 0.1, max tokens = 16,384.

## 2. Results

**Story Quality (LLM-as-Judge, GPT-4o evaluator, pairwise win rates vs. baseline):**

| Metric | Storytelling+Llam3 | Storytelling+Gemma |
|---|---|---|
| Creativity | 79.50% | **89.45%** |
| Coherence | **94.75%** | 92.15% |
| Engagement | 89.45% | **92.75%** |
| Relevance | 85.65% | 85.65% |
| Likelihood of Harm/Benefit | 96.85% | **96.05%** |
| **Overall (Avg)** | 89.24% | **91.21%** |

Baseline (plot-planning): Gemma 72.76%, Llama3 69.71%. Storytelling adds +15 to +25 points across dimensions.

**Human Evaluation** (2 graduate annotators, 100 pairs each, Cohen's kappa: 0.619-0.729):
- Storytelling preferred over baseline: 88% (Llama3), 76% (Gemma)

**Ablation Study (win rates vs. baseline):**
- Remove Environment Trajectories (role-play only): coherence drops 17.7 points for Gemma, relevance drops 12.2 points.
- Remove Role-Playing (sequential events only): creativity drops 10.0 points, engagement drops 8.8 points for Gemma.

**User Study (N=45), Harm Diversity:**

| Condition | Shannon Entropy (H) | Dominant Category |
|---|---|---|
| Control | 2.329 | Diminished well-being (32.3%), Service loss (24.2%), Privacy (22.6%) |
| Story-Only | 2.927 | More distributed across harm types |
| Story (Discussion) | **3.701** | Widest range; cultural harms, political harms, tech-facilitated violence appear *only* here |

Bootstrap t-tests: all pairwise differences significant at p < .001.

**User Study (N=45), Benefit Diversity:**

| Condition | Shannon Entropy (H) |
|---|---|
| Control | 2.407 |
| Story-Only | 3.242 |
| Story (Discussion) | **3.868** |

Benefits like accessibility/disability support, clinician workload relief, and transparency/trust appeared only in the Story condition.

**LLM-Based Survey (N=150 simulated personas)** reproduces the same monotonic entropy increases: Control (H=1.841 harms, H=2.415 benefits) → Story-Only (H=2.208, H=2.974) → Story (H=3.159, H=3.959), all p < .001.

**Lexical Diversity (DistinctL-n, Storytelling+Llam3):**
- DistinctL-3: 6.104 | DistinctL-4: 6.158 | DistinctL-5: 6.174
- Diverse Verbs: 0.937 | Avg Word Count: 179

## 3. Trade-offs

| Win | Loss |
|---|---|
| Broader harm recognition: participants in Story condition identified harms across all 17 categories vs. 3-4 dominant categories in Control | Synthetic scenarios: not validated against deployed systems; may not generalize to regulated clinical domains |
| Interactive discussion (Story) significantly outperforms passive reading (Story-Only) — entropy gap ~0.7-0.8 | Small, technically-skewed sample (N=45, mostly CS/AI students); findings do not generalize to clinicians or patients |
| Environment trajectory modeling is the single most important component (removing it drops coherence by ~18 points) | Reliance on proprietary GPT-4o API for generation and evaluation; exact reproducibility limited by API drift |
| Dual evaluation confirmation: LLM-as-judge and human annotators agree on overall ranking (Storytelling > All baselines) | Multi-agent discussion uses simulated personas, not real domain experts — no direct stakeholder validation |
| Story expansion: 38 AI concepts x 10 variations = 380 scenarios; scales beyond manual curation | Metrics measure breadth of harm/benefit awareness, not correctness or severity of identified risks |
| Cognitive scaffolding without replacing human judgment: LLMs generate stories; humans interpret harms | Short-term reflection only — measured immediately after discussion; no longitudinal follow-up |

## 4. Design Rationale

**Why speculative storytelling over automated risk detection?**

The authors argue that tools like RiskRAG automate risk identification but reduce human engagement in ethical reasoning. Speculative design (design fiction, "what-if" stories) preserves human reflection by making potential futures concrete and imaginable. Their framework is human-centered: LLMs generate scenarios as *cognitive scaffolds*, but humans interpret which outcomes are harms/benefits — the LLM never produces ethical conclusions.

**Why world agent + role-playing over single-pass generation?**

The ablation study empirically justifies this: environment trajectory modeling accounts for coherence (+17.7 pts when present), while role-playing accounts for creativity and engagement (+10.0 and +8.8 pts when present). Together they produce causally rich narratives where readers can trace *what changed, why it changed, and who was affected* — compared to flat plot descriptions from simpler methods.

**Why breadth (entropy) as primary metric?**

Early-stage ethical reflection, before deployment, requires broad consideration of potential impacts. A narrow focus on 3-4 familiar risks (privacy, well-being, service loss) misses context-dependent harms (cultural erasure, political exclusion) that only surfaced with interactive storytelling.

## 5. Limitations & Failure Modes

1. **Domain narrowness:** Scenarios limited to consumer health (not clinical decision support, finance, law). Framework untested in regulated domains where stakes are higher.
2. **Synthetic data:** All stories generated from LLM-synthesized use cases, not real deployed systems. Generated stories can reproduce bias or misleading claims (authors reviewed outputs and removed harmful content).
3. **Sample bias:** N=45 participants, predominantly technical (CS/Data Science/AI), 66.7% male. Findings do not generalize to clinicians, patients, or policymakers. The study measures short-term reflection, not long-term behavioral change.
4. **Single LLM judge:** Primary evaluations use GPT-4o as sole judge (mitigated by reporting human agreement and two additional judge models: Qwen2.5-72B and Gemma-3-27B).
5. **Simulated experts:** Red-team discussions use predefined LLM personas; do not capture real stakeholder diversity.
6. **Metric limitation:** Shannon entropy measures distributional breadth, not correctness, severity, or actionability of identified harms. High entropy could reflect superficial or implausible responses.
7. **Proprietary API dependence:** GPT-4o for generation and evaluation; API changes may break exact reproducibility.
8. **Scenarios are fictional and speculative:** Technologies described do not exist; every story was framed as hypothetical to avoid claims about real clinical products.

## 6. Transfer to Lyra

**The ONE transferable idea:** Use LLM-generated speculative "what-if" stories as cognitive scaffolds for red-teaming Lyra's agentic behaviors — generating diverse harm scenarios *before* deployment by having an LLM simulate role-playing interactions between the agent, users, and environment, then using the resulting narrative logs to broaden human red-team coverage of failure modes.

**Workstream Route:** §4.1 (Safety & Alignment) — this directly feeds the safety evaluation layer of Lyra's agent architecture. The storytelling framework provides a proactive, human-in-the-loop alternative to purely automated safety checks.

**Impact:** 4 — Adds a systematic, scalable method for surfacing context-dependent failure modes (cultural mismatches, privacy leakage in niche settings, political harms from autonomous agent decisions) that are unlikely to emerge from checklist-based safety audits.

**Effort:** 3 — Requires integrating a simulation pipeline (SPP + world agent pattern), building a red-team discussion interface (or adapting the Cinema of Thought pattern), and running user studies with Lyra-specific agent scenarios. Core prompting patterns are already released in the paper's repository.

**Tier:** Investigate — methodologically sound but studied only in consumer-health narrative contexts; needs adaptation to agentic-systems evaluation before investing in full implementation.
