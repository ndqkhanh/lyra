# Latent Agents: A Post-Training Procedure for Internalized Multi-Agent Debate

**Authors:** John Seon Keun Yi, Aaron Mueller, Dokyun Lee (Boston University)
**Venue:** arXiv:2604.24881v1 [cs.AI], 27 April 2026
**Code:** https://github.com/johnsk95/latent_agents

## 1. Mechanism

IMAD is a three-stage pipeline that distills explicit multi-agent debate into the latent space of a single LLM:

**Stage 0 — Dataset Construction:**
- Run explicit multi-agent debate (n=3 agents, m=2 rounds, majority vote) using GPT-3.5-turbo on 944 arithmetic problems (six random 2-digit numbers, mixed operations).
- Filter out debates without majority consensus; inject structure tags (`<|Agent 1|>`, `<|Round 1|>`, `<|Consensus|>`, `<|endofdebate|>`).
- Dataset format: `{Question, Trace, Answer}`.

**Stage 1 — Supervised Fine-Tuning (Debate Structure Learning):**
- Standard autoregressive next-token prediction (cross-entropy loss) over the entire debate trace (not just the consensus output), using LoRA adapters for 3-6 epochs.
- Purpose: teach the model to replicate the debate format — agent turn-taking, iterative refinement across rounds, and convergence to consensus.

**Stage 2 — Reinforcement Learning for Internalization (GRPO):**
- Fine-tune the SFT model using Group Relative Policy Optimization (GRPO).
- For each query x, sample k candidate outputs, score them with a dynamic reward function, construct a preference dataset on the fly, and update the policy.

The reward function is the critical mechanism:

```
r(x, y) = w_fmt * R_fmt + w_clip * R(y; l)
```

- **R_fmt** (format reward): binary — 1 if structural debate tags are present in the output, 0 otherwise. Weight w_fmt decays from 1.0 → 0.05 over training, gradually removing the incentive to verbalize the debate.
- **R(y; l)** (correctness with length clipping): binary — 1 if the correct answer y* appears within the first l tokens of output, 0 otherwise. The length limit l is annealed from l_0 = 2000 tokens (allowing full debate) down to l* = 500 tokens (only space for a concise answer).

The interplay: as w_fmt → 0 (stop rewarding the format) and l → l* (increasingly impossible to fit the full debate trace while getting the correct answer), the model's only viable strategy is to perform the multi-perspective analysis internally in its latent space.

**Activation Steering Analysis (Sections 3-4):**
- Extract agent-specific steering vectors using difference-in-means (Contrastive Activation Addition):
  ```
  v_i = (1/|D|) * Σ [h_ℓ(p, c_i) - h_ℓ(p, c_¬i)]
  ```
  where c_i is the target agent's response and c_¬i is the average of the other two agents' responses.
- At inference: h_ℓ ← h_ℓ + α · v_i with steering coefficient α.
- Positive α amplifies agent characteristics; negative α suppresses them.

## 2. Results

**Performance vs Efficiency (Table 1):**

| Model | Method | GSM8K (%) | MMLU-Pro (%) | BBH (%) | Token Cost (GSM8K) |
|-------|--------|-----------|-------------|---------|---------------------|
| LLaMA-3.1 8B | Single | 79.93 | 61.10 | 56.37 | 547 |
| LLaMA-3.1 8B | Debate (3-agent×2-round) | 83.03 | 64.60 | 51.06 | 5758 |
| LLaMA-3.1 8B | DebateGPT (distill final only) | 74.42 | 60.58 | 55.83 | 455 |
| LLaMA-3.1 8B | SFT (debate traces) | 79.23 | 75.60 | 54.91 | 992 |
| LLaMA-3.1 8B | **IMAD (SFT+RL)** | **85.20** | 62.00 | **58.53** | **644** |

- IMAD outperforms explicit Debate on GSM8K (+2.17pp) and BBH (+7.47pp) while using **6-21%** of the tokens (5-16× efficiency gain).
- RL stage reduces token consumption by **up to 66%** relative to SFT alone.
- Mistral Nemo 12B: IMAD beats Debate by **+18.97pp** on GSM8K (75.40% vs 61.03%).

**Agent Subspace Discovery (Section 3):**
- IMAD models show **+15.41% average improvement** in ROUGE-L AUC over base models when steered toward specific agents.
- Agent 3 (Program-of-Thought, code-like reasoning) shows strongest separation: **+24.97% ROUGE-1 AUC**, +21.63% ROUGE-L AUC.
- IMAD outperforms base at all steering coefficients — effects are present at α as low as 0.5.
- Cross-model validation: Qwen 2.5 7B shows +36-51% AUC gains; Mistral Nemo 12B shows +14-33%.

**Malicious Agent Control (Section 4):**
- Evil trait: IMAD achieves **complete suppression** (score → 0) at α = -3.0 to -5.0; base model retains residual malice (score 1.01 at α = -5.0).
- Hallucination trait: both models show linear suppression but neither reaches zero; IMAD preserves **stable GSM8K accuracy** across full steering range while base model collapses at extreme coefficients.
- Human-LLM judge agreement: **96.5% overall** (193/200 samples), validating the automated evaluation.

**Multi-task training ablation (Appendix J):** Training on 2000 expanded debate traces (arithmetic + GSM8K + BBH + CNN/DailyMail) yields modest further gains: IMAD (mixture) achieves 85.33% GSM8K, 66.00% MMLU-Pro, vs arithmetic-only IMAD's 85.20% and 62.00%.

## 3. Trade-offs

| Win | Lose |
|-----|------|
| **93% fewer tokens** than explicit multi-agent debate at inference (5-16× speedup) | **Upfront fine-tuning cost**: 3-6 epochs SFT + 2 epochs GRPO (LoRA mitigates this) |
| Matches or **exceeds** Debate accuracy: +2.17pp GSM8K (LLaMA), +18.97pp (Mistral) | Performance on **MMLU-Pro drops** under IMAD for LLaMA (62.00% vs 64.60% Debate) — format mismatch issue |
| **Generalizes** to new domains/tasks without training on those tasks (arithmetic → GSM8K, BBH, summarization) | No guarantee of correctness on out-of-distribution domains — SFT learns format, not reasoning |
| Creates **interpretable, separable agent subspaces** amenable to targeted control | **Any agent-specific steering degrades task performance** — model works best when all internalized agents operate at equal capacity |
| Malicious traits become **more localizable and suppressible** with less collateral damage | **Hallucination trait resists complete suppression** — more distributed across representations than evil trait |
| **Negative steering preserves coherence** in IMAD (perplexity stable/decreases) vs base model | SFT alone **does not guarantee correctness** — RL stage is essential; without it, hallucination and misalignment occur |
| Structure tags are **essential** — without them, agent subspaces are less distinct | **Extreme steering causes breakdown** even in IMAD: repetition loops, incoherence at α > 5.0 |
| **Prompting-only debate fails** — models omit rounds, confuse agent identities, especially with small context windows | Multi-task training gives **only marginal gains** over arithmetic-only IMAD — benefit saturates |

## 4. Design Rationale

The authors chose a **two-stage SFT+RL pipeline** over single-stage distillation because prompting alone cannot reliably induce multi-agent debate structure (models omit rounds, confuse identities, especially in smaller context windows — see Appendix H). SFT teaches the format; RL internalizes it. The **dynamic reward scheduling** (decaying format weight + shrinking length limit) is the key insight: instead of forcing the model to drop the debate abruptly, it creates an optimization landscape where internalization becomes the *only viable strategy* to earn the correctness reward. This is analogous to Hou et al. (2025)'s length annealing for chain-of-thought internalization, but repurposed for multi-agent debate. The authors **deliberately trained on arithmetic** (not benchmarks) to prove that the learned capability is structural (multi-perspective reasoning) rather than task-specific memorization. Using LoRA adapters rather than full fine-tuning keeps the method practical and preserves base model capabilities. The **contrastive activation addition** (CAA) method was chosen over probing classifiers because steering vectors can be applied at inference for causal intervention, not just correlational analysis.

## 5. Limitations & Failure Modes

- **Arithmetic-only training data**: training on only 944 arithmetic problems — scaling to richer reasoning traces (theorem proving, long-form QA) is unexplored. The mixture expansion (2000 traces) gives only marginal gains, suggesting data quality/diversity matters more than quantity.
- **MMLU-Pro regression**: IMAD occasionally underperforms explicit Debate on MMLU-Pro (LLaMA: 62.00% vs 64.60%) — multiple-choice format may not benefit from debate structure as much as free-response tasks.
- **Hallucination resistance**: the hallucination trait is more distributed across representations and cannot be fully suppressed (baseline score stays ~65, only drops linearly) — a fundamental limitation of the single-vector steering approach.
- **Agent-specific steering degrades performance**: strengthening any single agent persona reduces GSM8K accuracy — the model relies on balanced multi-perspective synthesis.
- **Two-round debate ceiling**: limited to 2-round, 3-agent debates — more rounds/agents may not scale gracefully with the current architecture.
- **GPT-3.5 generated traces**: training data quality is bounded by the teacher model; debates may contain reasoning errors that get baked into the internalized model.
- **No real-world safety deployment tested**: the malicious agent control is a proof-of-concept on constructed datasets — real jailbreaks may exploit different mechanisms.
- **LoRA adapters not merged**: separate adapters per model may complicate deployment vs a unified checkpoint.
- **Small-scale models only**: tested on 7B-12B models; behavior on 70B+ or frontier models is unknown.

## 6. Transfer to Lyra

**The One Idea:** The **dynamic reward scheduling with length annealing** technique (decaying format weight + shrinking length clip) for internalizing multi-agent processes into latent space. This directly transfers to Lyra's multi-agent architecture: instead of running explicit multi-turn debate in the Orchestrator → Worker → Critic loop, Lyra could internalize the full routing+critique cycle into a single fast pass, achieving 5-16× latency reduction while preserving multi-perspective reasoning quality.

**Workstream Route:** §4.2 (Agent Orchestration & Routing) — specifically the Orchestrator subsystem. The IMAD framework provides a principled way to distill the Orchestrator's multi-agent coordination into latent representations, reducing the sequential dependency on multiple agent calls while maintaining the benefits of diverse-agent synthesis.

**Impact:** 4 — High impact on inference latency and cost for Lyra's multi-agent collaborative reasoning loops.
**Effort:** 4 — Requires constructing debating dataset from Lyra's agent traces, implementing GRPO training pipeline with dynamic reward scheduling, and tuning LoRA adapters. Non-trivial but well-scoped.
**Tier:** Breakthrough — if successful, this would fundamentally change Lyra's multi-agent architecture from explicit sequential coordination to implicit latent synthesis, potentially the largest efficiency gain in the system.
