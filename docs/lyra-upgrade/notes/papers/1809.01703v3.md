## 1. Mechanism (Step-by-Step)

### Core Insight
Hyperbolic space expands **exponentially** with radius (vs. polynomially for Euclidean). This means moving a point to a given distance requires a smaller gradient force in hyperbolic space, making the pull-push mechanism of metric learning more effective for capturing tree-structured relationships between users and items.

### Step 1: Embedding in the Poincaré Ball
Users and items are represented as dense vectors constrained to the open n-dimensional unit ball:
```
D^n = {x ∈ R^n : ||x|| < 1}
```
Equipped with the Riemannian metric tensor:
```
g_p(x) = (2 / (1 - ||x||^2))^2 · g_e   (Equation 3)
```
The induced hyperbolic distance between two points x, y:
```
d_D(x, y) = cosh^{-1}(1 + 2 · ||x - y||^2 / ((1 - ||x||^2)(1 - ||y||^2)))   (Equation 4)
```

### Step 2: Möbius Gyrovector Space Operations
To generalize Euclidean operations (addition, scalar multiplication, exponential/log maps) to hyperbolic space, the paper uses Möbius gyrovector spaces with curvature parameter c:

**Möbius addition** (Equation 5):
```
x ⊕_c y = ((1 + 2c⟨x,y⟩ + c||y||^2)x + (1 - c||x||^2)y) / (1 + 2c⟨x,y⟩ + c^2||x||^2||y||^2)
```

**Möbius scalar multiplication** (Equation 6):
```
r ⊗_c x = (1/√c) · tanh(r · tanh^{-1}(√c · ||x||)) · x/||x||
```

**Generalized distance** (Equation 9):
```
d_c(x, y) = (2/√c) · tanh^{-1}(√c · ||(-x) ⊕_c y||)
```

When c→0, this recovers Euclidean distance; when c=1, it recovers the Poincaré ball distance. The curvature parameter c controls the ball radius as 1/√c.

### Step 3: Pull-and-Push Loss (Local Structure)
For each triplet (user i, positive item j, negative item k), the hinge loss pulls the positive item close and pushes the negative item away (Equation 11):
```
L_P = Σ_{(i,j)∈S} Σ_{(i,k)∉S} [m + d_D^2(i,j) - d_D^2(i,k)]_+
```
where m > 0 is the safety margin, [z]_+ = max(0, z), and S contains all observed (positive) user-item pairs.

### Step 4: Distortion Loss (Global Structure)
To preserve distances globally when embedding from Euclidean to hyperbolic space, a distortion term is added (Equation 12):
```
L_D = Σ_{(i,j)∈S} [|d_D(i,j) - d_E(i,j)| / d_E(i,j)]_+ + Σ_{(i,k)∉S} [|d_D(i,k) - d_E(i,k)| / d_E(i,k)]_+
```
Lower distortion means better preservation of original distance relationships.

### Step 5: Multi-Task Learning Objective (Equation 13)
```
min_Θ L = L_P + γ · L_D
```
where γ is the multi-task learning weight that balances precision (pull-push) against distortion (global structure preservation).

### Step 6: Riemannian SGD Optimization (Equation 14)
Parameters are updated via projected RSGD:
```
θ_{t+1} = R_{θ_t}(-η_t · ∇_R L(θ_t))
```
The Riemannian gradient is obtained by rescaling the Euclidean gradient with the inverse Poincaré metric tensor:
```
∇_R = ((1 - ||θ_t||^2)^2 / 4) · ∇_E
```
The retraction R projects points back onto the Poincaré ball after each update.

### Two Variants
- **HyperML**: Optimizes embeddings directly within the Poincaré ball using RSGD.
- **HyperTS**: First maps embeddings to the tangent space at the origin (which is Euclidean) via log_0, optimizes there, then maps back via exp_0.

### Ablation: Effect of Distortion Weight γ (Figure 4)
- **γ = 0** (no distortion): Performance drops by **-21.48%** (Meetup) and **-15.48%** (Automotive) compared to CML.
- **Optimal γ**: 0.75 (Meetup), 1.0 (Automotive) — dataset-dependent.
- Distortion term is essential: without it, hyperbolic metric learning underperforms Euclidean.

### Ablation: Effect of Curvature c (Table 4)
- Goodbooks: Best at c=0.5 (+4.87% over CML), worst at c=8.0 (-17.39%)
- Games: Best at c=2.0 (+18.61% over CML), worst at c=8.0 (-12.71%)
- Performance oscillates with c; requires per-dataset tuning

### HyperML vs HyperTS (Table 3)
Both variants achieve competitive results. HyperTS slightly edges HyperML on Clothing (+0.23%) and Cell Phones (+1.42%), while HyperML leads on Sports (+8.40%) and Meetup. No variant is universally superior.

## 3. Trade-offs (Wins vs Loses)

| Win | Cost/Loss |
|---|---|
| +32.32% max nDCG improvement over best Euclidean baseline (Sports & Outdoors) | Requires per-dataset tuning of curvature parameter c (range 0.5-8.0, oscillating performance) |
| Consistently outperforms all 5 Euclidean baselines across all 10 datasets | Requires per-dataset tuning of multi-task weight γ; wrong γ causes up to -21.48% regression |
| Hyperbolic space naturally captures user-item tree structures without explicit hierarchy modeling | Two variants (HyperML/HyperTS) — no clear winner, must trial both per dataset |
| Clustering emerges automatically: items liked by similar users cluster together, items of same genres co-locate | RSGD optimization adds complexity over standard SGD; gradient rescaling needed per step |
| Distortion term provides controllable precision-vs-preservation knob | Embedding norm must be constrained to <1 (open ball); initializations near origin required for convergence |
| Works particularly well on sparse datasets where Euclidean models struggle | Gains are modest (+0.4-0.8%) on large dense datasets where baselines are already strong |
| No negative sampling innovation needed — standard random sampling suffices | No investigation of negative sampling quality impact on hyperbolic space specifically |

## 4. Design Rationale

The key geometric intuition: a user-item triplet forms a small tree (user as root, positive/negative items as children). In Euclidean space, the ratio of child-child distance to sum-of-edges is constant regardless of edge length — failing to capture graph-like structure. In hyperbolic space, this ratio approaches 1 as edge length grows, making it possible to embed tree structures with near-zero distortion. The Poincaré ball model is chosen over the Lorentz/hyperboloid model for its **conformality** (angle preservation) and convenient parameterization. The pull-push mechanism from metric learning is retained for its simplicity and proven effectiveness in CF, while hyperbolic geometry provides the representational capacity boost. Möbius gyrovector spaces are used because they provide a principled algebraic framework that smoothly interpolates between hyperbolic (c>0) and Euclidean (c→0) operations, enabling direct comparison with Euclidean baselines. The distortion term is added because pure metric learning optimizes local triplet structure but can produce globally distorted embeddings — the multi-task framework balances both.

## 5. Limitations & Failure Modes

1. **No production-scale validation**: Largest dataset is 16M interactions (MovieLens20M) — no evaluation on 100M+ industrial-scale systems.
2. **Per-dataset hyperparameter sensitivity**: Both curvature c and distortion weight γ show oscillating performance and require dataset-specific tuning. No automated selection method is provided.
3. **Only implicit feedback**: Tested exclusively on one-class collaborative filtering. No extension to explicit ratings (1-5 stars) or multi-modal features is explored.
4. **No cold-start analysis**: Performance on new users/items with no interaction history is not evaluated.
5. **Single hyperbolic model**: Only the Poincaré ball is used. The Lorentz (hyperboloid) model, which offers more stable optimization, is not compared.
6. **No comparison with contemporary hyperbolic recommenders**: Chamberlain et al. (2019) proposed hyperbolic CF but is cited only as related work, not as a baseline.
7. **RSGD complexity**: Riemannian optimization requires gradient rescaling and projection at each step, adding computational overhead over standard SGD.
8. **No negative sampling ablation**: The effect of different negative sampling strategies (hard negatives, popularity-based) in hyperbolic space is unexplored.
9. **Static embeddings only**: No temporal dynamics or session-based recommendation capability.
10. **No fairness/diversity evaluation**: Only accuracy metrics reported; no analysis of recommendation diversity, serendipity, or demographic fairness.

## 6. Transfer to Lyra

### The ONE Transferable Idea
**Replace Euclidean embedding spaces with hyperbolic (Poincaré ball) spaces in Lyra's retrieval and intent-matching pipeline.** Just as HyperML replaced Euclidean distances in collaborative filtering with hyperbolic distances for better tree-structure capture, Lyra could embed documents, queries, and tool descriptions in hyperbolic space. The exponential expansion property would naturally encode the hierarchical taxonomy of user intents, tool categories, and document topics, improving nearest-neighbor retrieval quality — especially for sparse, long-tail queries where Euclidean embeddings underperform.
