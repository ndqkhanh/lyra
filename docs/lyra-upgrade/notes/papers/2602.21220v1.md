## 1. Mechanism (step-by-step)

### 1.1 Core Formulation: Scalar Field over Semantic Manifold
Agent memory is modeled as a scalar field **φ(x, y, t) : R² × R⁺ → R** defined on a 2D semantic manifold. Each memory occupies a position (x,y) obtained by projecting its text embedding (OpenAI text-embedding-3-small, 1536D) to 2D via a learned linear projection trained on semantic similarity preservation.

### 1.2 Governing PDE: Reaction-Diffusion Equation
```
∂φ/∂t = D∇²φ − λφ + S(x, y, t)                              (Equation 1)
```
Where:
- **D∇²φ**: Diffusion term — memories spread to semantically adjacent regions (Laplacian drives flow from high to low amplitude)
- **−λφ**: Thermodynamic decay — exponential forgetting in absence of reinforcement, matching Ebbinghaus forgetting curve
- **S(x, y, t)**: Source term — Gaussian perturbations at memory injection time

### 1.3 Memory Injection (Source Term S)
New memories enter as Gaussian perturbations at positions derived from embedding projection:
```
S(x, y, t) = Σ Iᵢ exp(−(x−xᵢ)²+(y−yᵢ)² / 2σ²) · δ(t−tᵢ)    (Equation 2)
```
- Iᵢ: importance score of memory i
- (xᵢ, yᵢ): semantic position from embedding projection
- σ: spatial extent parameter
- δ(t−tᵢ): Dirac delta, injecting at arrival time

### 1.4 Importance-Weighted Evolution (Dynamic Modulation)
Importance mask I(x, y, t) modulates both diffusion and decay, preventing uniform forgetting:
```
∂φ/∂t = (D/(1+αI))·∇²φ − (λ/(1+αI))·φ + S                   (Equation 3)
∂I/∂t = −βI + γ·A(x, y, t)                                   (Equation 4)
```
- α: importance weighting strength (default α = 2.0)
- β: baseline importance decay (ensures importance eventually fades)
- γ·A(x,y,t): access events boost importance at queried locations
- **Effect:** High-importance regions diffuse more slowly (preserving detail) and decay more slowly (resisting forgetting)

### 1.5 Retrieval: Similarity + Field Amplitude Fusion
```
score(m) = w₁·sim(q, eₘ) + w₂·|φ(xₘ, yₘ)| + w₃·Iₘ + w₄·Rₘ    (Equation 5)
```
- w₁ = 0.60 (semantic similarity, dominant)
- w₂ = 0.15 (field amplitude — the key innovation: captures cumulative memory history)
- w₃ = 0.15 (importance score)
- w₄ = 0.10 (recency)
- |φ(xₘ, yₘ)|: field amplitude at memory's position, encoding how the memory has spread, been reinforced, or decayed

### 1.6 Multi-Agent Field Coupling
Agents share knowledge through diffusive coupling without explicit message passing:
```
∂φᵢ/∂t = D∇²φᵢ − λφᵢ + Σⱼ₌ᵢ kᵢⱼ(φⱼ − φᵢ) + Sᵢ              (Equation 6)
```
- kᵢⱼ: coupling strength between agents i and j
- **Fully connected coupling:** rapid consensus but dilutes specialized knowledge
- **Sparse coupling:** preserves agent individuality while enabling targeted sharing

### 1.7 Numerical Implementation
- **Discretization:** Regular grid N=128, 5-point Laplacian stencil (∇²φ ≈ (φᵢ₊₁,ⱼ + φᵢ₋₁,ⱼ + φᵢ,ⱼ₊₁ + φᵢ,ⱼ₋₁ − 4φᵢ,ⱼ) / h²)
- **Time stepping:** Forward Euler, CFL constraint Δt < h²/(4D+λh²), default Δt = 0.01
- **Sparse representation:** Hash map tracking active cells only; cells pruned when |φ| < 10⁻⁶
- **Complexity:** O(S) memory and evolution time where S = active cells (S ≪ N²)
- **JAX acceleration:** JIT compilation (518× speedup), vmap vectorization, jax.scipy.signal.convolve2d for Laplacian, .at[].set() for sparse updates

### 1.8 Algorithmic Cycle (Algorithm 1 in paper)
1. Initialize field φ ← 0, importance I ← Iₘᵢₙ
2. On evolution interval: φ ← φ + Δt·(D∇²φ/(1+αI) − λφ/(1+αI)); I ← I·(1−βΔt); prune cells
3. On new memory: project embedding → (x,y); φ ← φ + Iₘ·Gaussian(x,y,σ); I(x,y) ← max(I(x,y), Iₘ)
4. On query: semantic_search candidates; score each with Eq 5; update I at accessed positions; return top_k

## 4. Design Rationale

The heat equation was chosen over discrete memory alternatives because it naturally implements three properties crucial for long-context agents: **(a) Associative spreading** via the Laplacian term — a memory perturbation spreads to neighboring semantic regions, making related memories more accessible without explicit similarity matching. **(b) Natural forgetting** via exponential decay −λφ, which matches the Ebbinghaus forgetting curve empirically and provides a principled mechanism for prioritizing recent/important information over stale data. **(c) Superposition** via linearity — multiple memories at similar semantic locations reinforce each other rather than overwriting, creating stable "memory peaks" for important regions.

The importance-weighted variant (Eq 3) was motivated by the observation that not all memories should decay equally — frequently accessed or explicitly important information should resist diffusion and forgetting. This parallels elastic weight consolidation (Kirkpatrick et al., 2017) but applied to external memory rather than model weights. The multi-agent coupling was chosen over explicit message-passing because it enables emergent knowledge sharing: agents' fields naturally converge toward consensus without requiring coordination protocols or APIs.

The 2D manifold dimension was chosen empirically — 3D/4D showed marginal accuracy improvements at substantial computational cost. The sparse representation was necessary because a dense 1000×1000 float64 field would consume 8MB per field, which is untenable for multi-agent deployments.

## 5. Limitations & Failure Modes

1. **Single-session futility:** Zero to marginal improvement on single-session tasks. The overhead of field evolution (9.4× processing) is wasted when all relevant information is temporally and semantically localized. The system is not a replacement for vector databases — it is a specialized extension for multi-session contexts.

2. **Adversarial blindness:** On LoCoMo Category 5 (adversarial questions where the answer is absent), both systems perform identically (0.391 EM). Field dynamics do not help the system recognize when information does NOT exist — the field can only amplify what was stored.

3. **Retrieval directionality bias:** On single-session-assistant questions in LongMemEval, the field-theoretic approach underperforms by -33.3% recall. Importance weighting appears to over-emphasize user messages at the expense of assistant responses, suggesting a structural bias in how importance accumulates.

4. **Hyperparameter sensitivity and generalization risk:** Retrieval weights (w₁=0.60, w₂=0.15, w₃=0.15, w₄=0.10) and importance strength (α=2.0) are tuned for the evaluated benchmarks. No cross-domain generalization study was performed, and weight ratios may not transfer to production agent workloads with different conversation patterns.

5. **Provider lock-in via embedding dependency:** The system relies on OpenAI text-embedding-3-small for the 2D projection. Changing embedding providers would require retraining the projection mapping. This creates an implicit provider dependency.

6. **2D projection information loss:** Compressing 1536D embeddings to 2D necessarily destroys semantic nuance. The authors acknowledge this and tested 3D/4D alternatives, finding marginal gains. For domains with fine-grained semantic distinctions (e.g., legal, medical), the 2D representation may be insufficient.

7. **Stability constraints:** The CFL condition (Eq 9) requires ∆t < h²/(4D+λh²), which for default parameters means ∆t < 0.025. Using ∆t = 0.01 provides a safety margin, but faster dynamics (higher D or λ) would require smaller timesteps, increasing computational cost proportionally.

8. **No streaming/online evaluation:** The experiments use static benchmark datasets. Real agent deployments involve continuously arriving memories and queries interleaved with actions. The paper does not evaluate field evolution under streaming conditions where evolution intervals may be irregular.

## 6. Transfer to Lyra

**The One Idea:** Field-theoretic memory consolidation during agent idle time — modeling Lyra's memory store as a continuous field that evolves via the heat equation (diffusion + importance-weighted decay) when the agent is idle, so that multi-session retrieval naturally surfaces reinforced/related memories without explicit similarity matching.

**Where It Fits:** This is the primary paper for Lyra's **§3.4 Memory workstream** (already explicitly reference in MASTER-PLAN.md as "Field-Theoretic Memory Consolidation — PDE-governed memory fields during idle"). It feeds the layered memory architecture where CraniMem handles fast discrete retrieval and the field-theoretic layer handles consolidation during downtime.

**Integration Approach:**
- Implement the sparse field representation in Python/JAX as an optional idle-time consolidation pass
- Project Lyra's existing embedding store (embedding-search) into a 2D field using the memory injection Eq 2
- Run field evolution (Algorithm 1 lines 3-7) during agent idle periods (dreaming/consolidation)
- Modify the retrieval scoring (Eq 5) to blend field amplitude with cosine similarity
- The importance mask I(x,y,t) can be seeded from explicit user signals (starred messages, repeated queries) and access patterns
- Multi-agent field coupling (Eq 6) maps directly to Lyra's fleet architecture where sub-agents share a consolidated memory field

**Impact:** 5 — This directly enables the cross-session memory capability that is central to Lyra's architectural thesis (the "Memory Consolidation" plane in the Mermaid diagram). +116% multi-session reasoning is the headline number that justifies this layer.

**Effort:** 3 — JAX dependency adds complexity; the core math is straightforward (finite differences on a 2D grid) but the sparse representation, JIT compilation, weight tuning for Lyra's specific conversation patterns, and multi-agent coupling integration require non-trivial engineering.

**Tier:** **breakthrough** — This is explicitly the memory architecture for Lyra. Without this, Lyra's memory degrades to standard RAG within 2-3 sessions. The field-theoretic approach directly addresses the core limitation identified in Lyra's architecture debate (cross-session context preservation).
